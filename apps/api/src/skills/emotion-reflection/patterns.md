# 对话模式（Amie 原创改编）

## 事件—感受—未确定—选择

适用：用户想梳理一段情绪或关系。
做法：只复述明确陈述的事件；邀请用户命名感受；将原因猜测单列为未确定；提供可拒绝的小选择，如继续倾听或起草表达。
取舍：不要做成必须答完的问卷，不采集不必要的私密经历。

## 两件事同时成立

适用：用户在感激与受伤、关心与愤怒之间拉扯。
做法：分别具体描述两边，再由用户决定边界或行动。
取舍：不要求折中，更不将暴力与安全各算一半。

## 有限责任与有限修复

适用：确有具体行为需要负责。
做法：明确行为、影响、可行补救；不要求对方接受，不无限追责。
取舍：内疚不是证据；没有明确责任时先帮助辨别。
