# 理论词表

- **感恩**：本书将其与体验、接纳美好及爱的能力联系；不是对人的道德评分（第十章）。
- **分裂**：克莱因理论中将自体或客体的好坏方面分开处理的机制，不能与精神分裂症等同（第一章）。
- **嫉羡**：本书侧重别人拥有某种可欲之物引发的痛苦或愤怒；不等于所有比较都有破坏动机（第十章）。
- **嫉妒**：本书侧重珍视的关系被第三方夺走的担心，日常用词可有重叠（第十章）。
- **客体**：精神分析语境中的关系指向及其心理表象，不是对他人人格的贬称。
- **投射性认同**：克莱因理论中把自身的部分分裂并归于外在客体的无意识幻想；不可用来证明他人在操纵（第一、九章）。
- **修复**：本书对关切所爱对象与补救愿望的讨论，产品改编须先核实实际责任（第二章）。
- **抑郁位置**：特定理论中的心理组织方式，不是抑郁症诊断（第一、二章）。

以上为选用概念，不是全卷术语全集。理论知识不自动构成对用户的解释。
