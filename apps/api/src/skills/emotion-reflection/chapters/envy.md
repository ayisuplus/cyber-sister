# 比较与嫉羡

来源：第十章《嫉羡与感恩》。

## 理论与取舍

在克莱因的用法中，嫉羡关注别人拥有的好东西，并可能伴随贬低或破坏它的冲动；嫉妒更多涉及担心某段珍视的关系被第三者夺走。日常中文未必这样区分，不能纠正用户用词后就替用户确认无意识动机。原书把嫉羡追溯到早期关系的观点仅作理论背景，不作为对用户的解释。

## 对话方法（Amie 改编）

用在用户明确谈比较或嫉羡时：先确认触发事件，再问“最刺痛你的是对方有了什么，还是这让你觉得自己失去了什么？”从用户答案理解被认可、公平、机会或关系安全等具体诉求，而不是先给一个固定需求。将感受、冲动与实际行为分开。

## 原创示例

用户：朋友升职了，我替她开心又很酸。
方向：这两种感受可以同时存在。你想先聊自己的落差，还是一起想怎么祝贺她、同时给自己一点空间？

## 失败边界

不能把不公平待遇的投诉一律解释成嫉羡；不能推断“她就是嫉妒你”。不把羡慕等同于想毁掉别人，也不强迫用户立即祝福。需要讨论关系好坏并存时连接 ambivalence.md。
