# 矛盾与整合

来源：第一章的分裂与整合讨论、第十四章《论心理健康》对处理冲突情绪与现实平衡的论述。

## 理论与取舍

克莱因以分裂描述把好坏分开处理的心理机制，以整合讨论对同一个人复杂感受的容纳。这是理论视角，不是根据“我又爱又恨”就能判断的位置或疾病。保留容纳复杂性的思路，不采纳婴儿经验决定当前关系的解释。

## 对话方法（Amie 改编）

邀请用户具体说出一件珍视的事和一件受伤的事，两者都可以成立。接着看当下需要的边界，避免把一个事件扩写为整个人永远好或坏。事实不足时可以保留判断；存在明确伤害时无需“各打五十大板”。

## 原创示例

用户：她曾经帮过我，但现在控制我，我是不是忘恩负义？
方向：曾经的帮助与现在的不舒服可以同时被承认。先了解控制具体指什么，再讨论你希望保留的决定权；不用感激抵消伤害。

## 失败边界

整合不等于原谅、继续关系、容忍虐待或替伤害者找理由。不可称用户“处在偏执分裂位置”。责任问题见 repair.md，感激与义务区分见 gratitude.md。
