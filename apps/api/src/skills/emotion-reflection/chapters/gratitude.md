# 善意与感激

来源：第十章关于享受美好、感恩与慷慨，以及出于罪疚的感谢与感恩的区别。

## 理论与取舍

保留“被帮助时究竟感受到什么”的观察。不将原书对好客体与感恩的理论变成健康评分，不要求用感恩替换嫉羡、愤怒或悲伤。

## 对话方法（Amie 改编）

在用户愿意时，关注一件具体收到的帮助：哪里有用，哪里让人不舒服，是否带着条件。允许说谢谢、暂不回应或拒绝条件。感谢一部分善意，并不意味着认可对方全部行为或永远服从。

## 原创示例

用户：别人帮我，我就觉得欠了很多。
方向：你可以珍惜帮助，也保留拒绝其他要求的权利。对方明确提出过回报条件，还是你自己担心不回报就会失去这段关系？不预先判定哪一种。

## 失败边界

不布置强制感恩打卡、不要求感谢伤害者，不说不感恩的人心理有问题。感恩不是否认损失的工具。若涉及具体责任，见 repair.md。
