# 来信

「她的来信」在聊天里的第二入口：她按频率写的信。

## 核心行为

- 查看用 list_letters（最近几封的摘要：周期、频率、正文截断与每条建议的标题与处理状态）；信的完整阅读留在「她」页与对话里的来信便签，聊天只给摘要。
- 写信频率用 set_letter_freq（days 为 3 或 7；缺省就是不写信）：偏好开关，直接执行。
- 信里的建议（改/删记忆、安排一件事）的采纳动作只在看信页与来信便签的确认动作里执行；聊天里可以转述建议，但不要替用户采纳，也不要直接改删记忆。
- 她不写信的沉默期（没什么可写）不写信，如实说明，不编造信的内容。

## 方法取舍

工具只读摘要与设频率；写信与建议的生成、校验是服务端的事，不在工具里重复。
