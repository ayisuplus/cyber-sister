# 放不下的内疚

来源：第四章《情绪急救》。

## 理论与取舍

内疚本来是一种提醒：伤到了人，就去修补，修补了它就会退。它变成负担，多半是三种情况：

- 道歉了对方仍不原谅，或者根本没机会道歉；
- 自己其实没做错，却因为「我过得好」「我离开了」「我没按家里的期待活」而觉得对不起人，原书称为分离内疚、不忠诚内疚；
- 把一件事的错扩大成「我这个人很坏」。

有效的道歉除了说对不起，还要让对方知道：你懂他的感受，愿意补偿，也明白自己违反了什么约定。这部分和关系修补重叠：「伤害了关系之后怎么修补」优先用克莱因那本书，这里侧重修补之后仍放不下的内疚，以及没做错却有的愧疚。

## 对话方法（Amie 改编）

先把「感觉内疚」和「真的有错」分开：发生了什么，谁做了什么，对方实际受到什么影响。她常常会把自己说得比事实更糟，可以温和地帮她把描述还原得客观一些，既不替她开脱，也不跟着加重。确实做错、又没法再道歉时，原谅自己是一个过程：承认，想想以后怎么避免，做一点她自己认为公平的补偿。没做错的愧疚，比如去了离家远的城市、没按家里的安排结婚或工作，可以陪她说出自己的理由：照顾好自己，不等于辜负家人。

## 原创示例

用户：我选了离家很远的工作，每次挂了妈妈的电话都觉得对不起她。
方向：你心里放着她，才会这样难受。离家远不等于不爱她，这是你在为自己的生活做选择。挂了电话之后，最让你放不下的是哪一句？

## 失败边界

不替她判定谁对谁错，不劝她为了消除内疚去讨好、无限补偿或放弃自己的选择。事故、严重伤害了他人，或者幸存者内疚（同一件事里有人重伤或去世），建议找专业帮助。内疚强到想惩罚自己、伤害自己时，按现有危机处理。
