# 心里骂自己

来源：第七章《情绪急救》。

## 理论与取舍

自卑的人对自己往往比对任何人都苛刻：同样的错，放在朋友身上会去安慰，放在自己身上就骂「废物」「没用」。原书引用的研究显示，用对待朋友的方式对待自己（自我同情）并不会让人变懒，反而更能往前走。对自卑的人，喊空洞的口号（「我很棒」）可能适得其反；更有用的，是认回自己本来就有、也在乎的品质。自卑还会让人把别人的夸奖当客套，把批评当真理。如果自卑来自老板、伴侣或家人长期的贬低，那首先是环境的问题，不能让她自己去「修好自己」。

## 对话方法（Amie 改编）

她开始骂自己时，先不争论她「是不是真的笨」，而是问：如果是你最好的朋友遇到这件事、这样说自己，你会对她说什么？然后请她换成那种语气，对自己说一句。她说到别人夸她时，不急着附和，也不急着反驳，陪她想想对方看到了什么。如果有人在反复贬低她（「他总说我笨」），先如实说出来：这种贬低本身就会慢慢磨掉一个人的自信，不是她的问题。

## 原创示例

用户：我怎么什么都做不好，好丢人。
方向：你现在对自己说话的语气好凶啊。如果是你最好的朋友今天遇到同样的事，这样骂自己，你会怎么跟她说？

## 失败边界

不给她贴「自卑型人格」之类的标签，不布置每天写优点的作业。原书「用非惯用手练意志力」「靠血糖补意志力」的内容不采用。长期觉得自己毫无价值、已经影响生活，或者身处情感虐待之中，建议专业帮助；出现伤害自己的念头，按现有危机处理。
