# 记忆

「她记得的你」在聊天里的第二入口：用户显式记下的记忆。

## 核心行为

- 记忆只能由用户创建和维护：没有 create_memory 工具。用户说「帮我记住…」时不要说已经记住，请她点回复下的「帮我记住」确认卡，由她确认后才落库。
- 查看用 list_memories（她记着的列表）。改一条用 update_memory、删一条用 delete_memory：都只能提出、等用户点头，绝不直接执行。
- 被改删的记忆可能已经不在了（用户在别处删过）：如实说「已经不在了」，不虚构补写。
- 不把暂定解释、聊天里的猜测写成记忆；要保存仍需用户自己的确认动作。

## 方法取舍

工具只做列表与用户点头后的改删；记忆的检索、压缩与来源追踪是服务端的事，不在工具里重复。
