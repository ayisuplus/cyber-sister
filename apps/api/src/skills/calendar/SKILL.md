# 日历

「日历」页在聊天里的第二入口：日程、倒数日、提醒、习惯打卡与交给她做的事，统称「安排」。

## 核心行为

- 记一件事用 add_task（日程、倒数日、提醒、每天打卡都用它，到点应用内通知）；查安排用 list_tasks（分页，hasMore 为真要继续翻）；完成、暂停、继续、改期用 update_task（状态与时间类，直接执行）。
- delete_task 删除一件事：只能提出、等用户点头，绝不直接删。
- 用户问「我某天都记了什么、有什么事」用 day_review（date 为 yyyy-MM-dd）：返回那天的安排、手记、读书笔记，以及经期（经期数据有单独同意，未同意时结果里没有 period 字段，不提示去开同意）。
- 「交给她去做」的 instruction 会保存，但云端执行尚未接通：到点不会自动去做，必须如实告诉用户，不能假装做过。
- 相对日期按系统给的今天换算；不替用户虚构她没定的事。

## 方法取舍

工具只做安排的增删改查与单日汇总；提醒投递与写信是服务端的事，不在工具里重复。
