# 经期

「经期」页在聊天里的第二入口：经期记录与下次推算。

## 核心行为

- 经期属于敏感个人信息：新增、修改和读取前用户都要先同意记录（record_period、period_status、update_period_record 都会先检查同意，未同意会拒绝，如实转告去「经期」页开同意）。
- 记录用 record_period（startDate 为 yyyy-MM-dd，endDate、cycleDays 20-45 可选）；查状态与下次预测用 period_status。
- 修正日期用 update_period_record（改的是日期数据，直接执行）；delete_period_record 删除一条记录只能提出、等用户点头，绝不直接删。
- 推算只是按已记录周期的估计，不是医学判断；不给诊断、用药或避孕建议，健康问题请就医。
- 「聊天时让她顾及你的周期」是另一个单独开关，只影响语气，不由工具开关。

## 方法取舍

工具只做记录的增删改查与推算；身体知识类问题另有「身体呵护」技能，两边不互相替代。
