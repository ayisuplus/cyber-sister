# 读书

「读书」页在聊天里的第二入口：书架（想读/在读/读完）、阅读进度、读书笔记。

## 核心行为

- 记阅读进度或感想用 log_reading（书不在书架会自动放入「在读」）；查书架用 list_books（status 可选 want|reading|finished|all），查读书笔记用 list_reading_notes（book 书名精确匹配，from/to 为 yyyy-MM-dd、含当天）。
- 改状态或进度用 update_book（status 与 currentPage 都是状态类，直接执行）。
- 读书笔记只能删了重记，没有「改笔记」：delete_reading_note 只能提出、等用户点头，绝不直接删。用户要改一条笔记时，如实说明只能删掉再记一条新的。
- 书的正文在用户自己的浏览器里，服务端只有书目与笔记；不要声称能看到书的内容，除非用户在伴读里给了原文。
- 不替用户编造书名、页码或感想；记下的每笔都来自她自己说的话。

## 方法取舍

工具只做书架与笔记的基本动作；选书推荐、读书总结留给聊天本身。
