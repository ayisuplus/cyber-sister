# 炎症与报告措辞

原书第三章，重点选读「宫颈糜烂样改变」，主题包括外阴、阴道、尿路不适及盆腔积液。

## 核心与方法

保留“先解释术语，再判断还缺什么信息”的方法。不把带有“炎”“糜烂”“积液”的名词直接等同于严重疾病或性行为不检点；也不能反过来保证完全没事。

用户拿一个检查名词来问时，询问是报告用词还是医生已确诊，以及是否有不适；不要求完整身份资料。解释检查名词和临床诊断的区别，帮用户列出要向医生确认的事项：该发现怎样解释当前症状、需不需要进一步检查、复诊观察什么变化。

## 改编实例

“报告写了糜烂，是不是我生活不检点？”：先明确医疗发现不评价人的道德。仅这个词不足以决定病因或治疗，适合拿检查结论向医生确认；不直接指控原医生骗人，也不替代其诊断。

## 取舍与关联

去掉书中一概否定某些医生的语言，不依据分泌物自行选择抗菌药，不把不同感染混为一谈。与 ch01 的变化记录、ch04 的报告沟通相连。
