# 分泌物与清洁

原书第一章，重点选读「什么是白带」「什么样的白带是正常的」「私处怎么洗」。

## 核心与方法

白带是正常身体分泌物，数量和性状可随周期变化。把“发现变化”与“证明疾病”分开。先了解相较平时的变化和伴随不适，再决定是一般解释还是建议检查。不能把清洁程度或性经历当成病因判断。

用户困惑内裤上的痕迹时，先说明分泌物本身不是脏或排毒的证据。出现异味、瘙痒、疼痛、异常出血等变化时建议专业评估，不按颜色给疾病对照诊断。清洁建议限于温和清洗外阴；不建议冲洗阴道或用香味产品掩盖症状。

## 改编实例

用户：白带让我觉得自己很脏。
回应方向：分泌物本身是正常现象，不说明你不干净。你更想了解日常清洁，还是最近出现了和平常不一样的不适？只问用户愿意分享的信息。
