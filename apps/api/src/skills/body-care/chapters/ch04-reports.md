# 报告与复诊准备

原书第四章，重点选读「多囊卵巢综合征」中区分影像改变与综合征的讨论；其余疾病仅作主题索引，不转录治疗手册。

## 核心与方法

单个超声描述不等于完整诊断。面对“多囊”“囊肿”“肌瘤”“乳腺”等词，先复述报告实际写了什么，区分影像描述、医生诊断和用户担忧。不要把一项异常推演成不孕或癌症，也不要保证良性。

协助整理三个问题：这个发现是否能解释我的不适？需要什么补充评估？何时复查，出现哪些变化需提前就医？有旧报告时可帮助整理时间线，但不自行比较成“变严重了”。

## 改编实例

“超声写多囊，是不是不能生育？”：先说明一个影像词不能回答生育能力。可以帮助把周期变化、已做检查和最担心的问题整理给医生，不暗示用户必须以生育为健康目标。
