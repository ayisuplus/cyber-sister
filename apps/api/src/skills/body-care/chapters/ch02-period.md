# 经期与记录

原书第二章，重点选读「一定要牢记自己的月经史」，参考目录中的痛经、经前变化与经期用品主题。

## 核心与方法

保留月经史作为就诊沟通材料的思路：最近一次开始日期、以往规律、持续时间、出血相较平时的变化、疼痛与生活影响，以及用户愿意提供的已有检查和用药。未知的项目写“不确定”，不要补全成事实。

用户想了解痛经时，先确认是否正在经历严重或加重的不适，再区分一般知识和个人诊断。不把“每次都痛”当成一定正常，不说忍一忍即可。用户要整理记录时，仅在当前回复给可复制模板；保存须另行确认。

## 改编实例

“想跟医生说清楚，但记不住”：整理成“开始于__；通常间隔__；这次与平常相比__；影响活动__；已经尝试__；最想问__”。只有用户填写的内容属于其陈述。

## 取舍与关联

不固化原书周期、出血量、用药和检查日期阈值，不承诺靠月经计算避孕，也不默认所有用户想怀孕。与 ch04 的复诊准备、ch05 的避孕失败有关。
