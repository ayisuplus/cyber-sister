# 身体差异与自主权

原书第六章，选择身体外观、私处营销、处女膜和 HPV 等主题；重点核对「如何看待处女膜修复」，不照搬其轶事与推断。

## 核心与方法

把健康需求和外界审美压力分开。先问用户正在经历实际不适，还是被某个评价或广告困扰。不能用颜色、松紧、处女膜外观判断性经历或价值；所谓处女检测没有科学依据。

面对卵巢保养、私处美白、紧致营销，不从“缺陷”出发推销产品；帮助用户问清目标、证据、风险和可替代选择。对 HPV 等结果不作忠诚度或道德推断，不给过时的疫苗年龄、剂次与筛查安排。

## 改编实例

“对象觉得颜色深就说明经历多”：明确外观不能作为性经历的证明。不顺势要求照片或检测，询问用户想了解知识还是一起整理表达边界的话。

## 取舍与关联

不沿用原书性别刻板印象，不承诺检查一定不痛。检查中用户可以表达不适、要求暂停并和医护商量调整，不能归咎为“不配合”。处女检测立场来源 WHO；检查自主权参考 NHS，见 sources.md。与所有主题的去羞耻化表达相连。
