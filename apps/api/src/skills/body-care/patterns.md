# 就诊准备与沟通模式

## 事实—担忧—问题

适用：用户担忧报告或症状，想准备就诊。
做法：把用户明确说出的时间、变化、检查整理为事实，把担忧单列，再列最多三个希望医生回答的问题。不知道的写“不确定”。
代价：这是沟通材料，不是诊断；不要为了表格完整强迫披露隐私。

## 机制—差异—行动

适用：用户将分泌物或外观变化理解为脏或缺陷。
做法：用一个简单机制说明一般现象，承认个体差异，再根据有没有不适给下一步。
代价：机制解释不能证明当前症状无害。

## 暂停—说明—选择

适用：害怕或经历检查疼痛。
做法：可以向医护表达“我现在不舒服，请先暂停，解释下一步和可调整的方式”。是否继续由用户与医护沟通。
代价：不承诺具体医院一定提供某个替代方案，不把疼痛归咎于紧张。

以上流程是 Amie 根据阅读目标设计的产品方法，不是书中命名的框架。
