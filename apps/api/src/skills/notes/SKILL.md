# 手记

「手记」页在聊天里的第二入口：今天的心情与随笔（一天一篇）。

## 核心行为

- 写今天的心情与随笔用 add_diary（一天一篇，心情词表 happy|neutral|sad|angry|anxious）。今天已经写过再写就是覆盖那一篇：先在聊天里提出「把今天的手记改成新的说法」，等用户点头才执行，绝不直接覆盖。
- 用户问「我某天/某月记了什么」用 list_diary（day 为 yyyy-MM-dd，month 为 yyyy-MM，都缺省查今天）；问「我哪天都记了什么、有什么事」先用「日历」技能的 day_review 看那天的完整图景。
- diary_status 只回答今天写没写。删掉某天的手记用 delete_diary：只能提出、等用户点头，绝不直接删。
- 读书感想不走手记工具：用「读书」技能的 log_reading 记到那本书下。要她长期记住的事实走「帮我记住」，不写进手记冒充记忆。
- 一天只有一篇手记，再写是改不是加；不要替用户编造、补写或润色她没说的内容。

## 方法取舍

手记工具只做查与写的基本动作；生成日记、总结心情留给聊天本身，不在工具里代写。
