## 📌 TL;DR（执行摘要）
- MVP 核心链路已通，但五指标**零真实基线**，当前最大风险是"用假设代替事实"。
- 主线定为**先验证后增强**：补真实埋点与用户访谈优先于任何新功能，首轮只验证"信任度≥60%、完成率≥35%"两个生死线。

- 定位"AI 可执行妆教"开创者，以"原图分区标注 + 本地隐私 + CPS"避开滤镜/AR 正面竞争。

## 1. 当前指标表现（数析）
- 零基线：`data/analytics.jsonl` 仅 2 行测试事件（sessionId 均 null），五指标（上传率≥40% / 信任度≥60% / 完成率≥35% / 分享率≥15% / D7 留存≥10%）**全是待验证假设**。
- 市场底盘大：彩妆约 1261 亿（2024E）、虚拟试妆渗透 79%、58% 接受 AI 推荐、CPS 佣金 10–50%。
- 数据建议（已定 P0）：先埋核心漏斗 `upload_success / analysis_complete+信任点击 / result_share / sessionId`；首轮优先验证"信任度≥60%、完成率≥35%"决定产品是否成立；上线 2 周攒 ≥200 有效会话再读首批漏斗，防小样本误判。

## 2. 用户反馈摘要（瑞思）
- 三类人群（新手小白 / 进阶爱好者 / 社交分享型）**未验证**，仅为画像假设。
- 五大痛点：① 教程与脸型脱节；② 色号选择难（屏幕色差）；③ 步骤多、术语门槛高；④ 隐私顾虑（自拍被上传/训练）；⑤ 缺回看收藏。
- 修复建议：先验证（问卷 + 5–10 人访谈 + 真实埋点 + 明确首批受众与隐私立场，**先服务透一类人**）；后增强（CPS 真实库 / 回看收藏 / 场景快速妆 / 剥离图像生成与品牌站）。

## 3. 竞品动态（竞析）
- 全市场空缺"原图标注教学 + 本地隐私 + CPS"；滤镜/AR 试妆（美图秀秀、YouCam、ModiFace）只给结果不给教学，不构成正面竞争。
- 主要竞品：美图秀秀（5 亿用户，滤镜强不可执行）、小红书（2–3 亿月活，内容强难映射自己脸）、YouCam/ModiFace（AR 领先）、你今天真好看（测肤）、Lensa/海外生成器、完美日记/花西子（品牌工具）。
- 定位：**"AI 可执行妆教"开创者**——以"本人原图分区标注 + 本地隐私 + 后续 CPS"建立差异。

## 5. 利益相关者沟通要点

**高管视图（战略 / 业务影响 / 决策）**
1. 产品未验证：五指标零基线，本阶段目标是"最小成本证伪/证实假设"，非扩功能。
2. 机会真实但需先证明：1261 亿底盘 + 79% 渗透 + 58% 接受 AI，但须过"信任度≥60%、完成率≥35%"生死线。
3. 范围治理降本聚焦：剥离图像生成、品牌站独立、脚本归档，主分支回归精简。
4. 关键决策点：W4–5 依首批漏斗决定继续 / 调人群 / 止损。
5. 远期变现清晰：CPS（10–50% 佣金）为承接路径，本期不提前铺货。

**工程视图（技术 / 时间线 / 依赖）**
1. P0 埋点：`upload_success`、`analysis_complete`(带信任点击)、`result_share`、`sessionId` 串联，2 周上线。
2. 范围治理三动作：① `generate` 移出主分支至 `feature/image-generation`；② `brandsite/` 独立部署 CI 解耦；③ `scripts/` 迁 `scripts/archive/`。
3. 剥离配套回归：移除 generate 路由引用、更新 `scope.md`、跑通主流程 e2e 防回归。
4. 时间线紧耦合：埋点(W1–2) → 累积会话(W2–4) → 漏斗报告(W4) → 生死线决策(W4–5)。
5. 隐私约束：自拍本地处理不上传，埋点不含 PII。

**设计视图（体验主线 / 内容策略 / 一致性）**
1. 主线"原图分区标注教学"是唯一差异点，近期不堆新视觉，先做到看懂跟练。
2. 术语门槛是新手阻力：专业词（截断式眼妆 / 八字眉 / 面部折叠度）配括注或图标。
3. 先透一类人（建议新手小白）：步骤少、工具常见、先画哪/用什么/画在哪清晰。
4. 信任感来自"本地分析 + 低置信提示"：明示仅本地处理，低置信结果预警。
5. 结果卡为裂变入口：美观 + 自然文案 + 回看二维码，服务社交分享型。
