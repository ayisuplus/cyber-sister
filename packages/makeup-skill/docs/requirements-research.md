# 妆语 MakeupWhisper — 需求调研

> 调研目标：明确 AI 妆教产品在中国女性用户市场中的定位、核心痛点、竞品差距与 MVP 需求边界，为后续迭代提供决策依据。

## 1. 产品定位

- **产品名**：妆语（MakeupWhisper）
- **一句话定位**：上传一张自拍，AI 在原图上分区标注、手把手教用户画适合自己的妆容。
- **差异化**：不是「滤镜式试妆」，也不是「博主视频教程」，而是基于个人脸型的「可执行化妆说明书」。
- **商业模式（远期）**：CPS 产品推荐（粉底液、眼影盘、口红等）+ 品牌内容合作。

## 2. 目标用户画像

### 2.1 核心人群

| 维度      | 描述                                                   |
| --------- | ------------------------------------------------------ |
| 性别/年龄 | 中国女性，18–35 岁                                     |
| 地域      | 一线/新一线为主，逐步下沉                              |
| 化妆水平  | 初学者（约 60%）+ 中级进阶者（约 40%）                 |
| 消费特征  | 愿意为「适合我」的产品付费，但对专业术语和复杂步骤敏感 |
| 常用平台  | 小红书、抖音、B站、微信                                |

### 2.2 用户分层

| 分层       | 特征                              | 核心诉求                 |
| ---------- | --------------------------------- | ------------------------ |
| 新手小白   | 不会判断脸型/眼型，买化妆品易踩雷 | 简单、确定、可跟练的步骤 |
| 进阶爱好者 | 已会基础妆，想找到个人风格        | 针对自己五官的进阶技巧   |
| 社交分享型 | 重视结果卡颜值与文案              | 一键生成小红书风格分享图 |

## 3. 用户痛点与需求

### 3.1 主要痛点

1. **教程与个人脸型脱节**
   - 博主脸型、眼型、肤色与观众不同，「照搬」效果差。
   - 用户不知道自己属于圆脸/方脸/长脸，无法判断教程是否适用。

2. **色号选择困难**
   - 粉底、口红、眼影的热门色号不一定适合自身肤色。
   - 线上试色受屏幕色差影响大。

3. **步骤多、术语多**
   - 新手看不懂「截断式眼妆」「八字眉」「面部折叠度」等术语。
   - 缺少「先画哪、用什么、画在哪里」的可视化指引。

4. **隐私顾虑**
   - 担心自拍被上传、存储或用于训练模型。

### 3.2 需求优先级（MoSCoW）

| 优先级 | 需求项                           | 说明                             |
| ------ | -------------------------------- | -------------------------------- |
| Must   | 本地人脸分析，不上传原图         | 解决隐私顾虑，也是产品核心差异点 |
| Must   | 基于脸型的妆容推荐               | 至少覆盖脸型、肤色、眼型         |
| Must   | 原图分区标注教学                 | 每一步在对应五官区域显示覆盖区   |
| Should | 产品色号/类型推荐                | 为 CPS 变现预留接口              |
| Should | 小红书风格结果卡                 | 提升分享率与裂变                 |
| Could  | LLM 个性化解释                   | 让推荐理由更温暖                 |
| Won't  | 实时 AR 试妆、医美诊断、电商下单 | 明确超范围，不在 MVP 内          |

## 4. 竞品分析

### 4.1 直接竞品

| 产品                | 模式          | 优势                   | 劣势                 |
| ------------------- | ------------- | ---------------------- | -------------------- |
| 美图秀秀「AI 妆容」 | 滤镜/一键上妆 | 视觉冲击强、用户基数大 | 不可执行，只是滤镜   |
| 小红书美妆博主      | 视频教程      | 内容丰富、种草力强     | 无法映射到自己脸上   |
| 你今天真好看（APP） | 拍照测肤+推荐 | 皮肤检测成熟           | 侧重护肤，非妆容教学 |
| 完美日记「美妆蛋」  | 品牌工具+电商 | 产品与内容结合         | 局限于自有品牌       |

### 4.2 间接竞品

- **抖音/快手短视频**：碎片化、算法推荐强，但缺乏系统性。
- **线下专柜试妆**：体验真实，但时间成本高、有推销压力。

### 4.3 竞品差距机会

- 市面上缺少「在本人原图上逐步标注教学」的工具。
- 本地化处理自拍可降低隐私门槛，提升首次上传率。
- 结合 CPS 推荐，可打通「教学 → 产品 → 购买」链路。

## 5. 市场规模与机会

- **美妆电商**：中国彩妆市场规模超 1000 亿元，线上渗透率持续提升。
- **内容种草**：小红书美妆笔记日均曝光量巨大，「适合我」是高频搜索词。
- **AI 工具渗透**：女性用户对 AI 测肤、AI 试妆接受度高，但更看重结果可信度。
- **机会点**：以「可执行教学」为切入点，避开与大厂滤镜产品的正面竞争，建立差异化心智。

## 6. 核心使用场景

### 场景 1：出门前快速上妆（5–10 分钟）

- 用户上传自拍，获得一款日常通勤妆的简化版步骤。
- 重点：步骤少、工具常见、可快速完成。

### 场景 2：约会/面试/聚会前选择妆容

- 用户根据场景标签（通勤/约会/面试/晚宴）选择推荐妆容。
- 重点：风格明确、避雷提示、产品推荐。

### 场景 3：学习进阶技巧

- 用户反复观看某个步骤（如眼妆、修容）的原图标注。
- 重点：可跳转、可重播、术语解释。

### 场景 4：社交分享

- 用户保存结果卡或复制文案到小红书/微信。
- 内测重点：卡片美观、文案自然；回看二维码属于迭代阶段，不在当前构建中展示。

## 7. 功能需求清单

### 7.1 MVP 必备

- 自拍上传（相册/拍照/拖拽/粘贴）+ 10MB 限制
- 浏览器本地 MediaPipe 人脸关键点检测
- 三庭五眼 / 脸型 / 肤色 / 眼型 / 鼻型分析
- 3 套妆容推荐 + 匹配度理由
- 分步教学 + 原图 Canvas 分区标注
- 教学资源聚合
- 结果卡生成 + 保存图片 + 复制文案

### 7.2 迭代阶段

- LLM 个性化推荐理由
- 真实 CPS 产品库与链接
- 二维码扫码回看教程
- 用户历史/收藏
- 肤色分析算法调优

## 8. 非功能需求

| 类别     | 要求                                             |
| -------- | ------------------------------------------------ |
| 隐私     | 自拍不上传服务器，仅发送结构化特征；埋点不含 PII |
| 性能     | MediaPipe 模型首次加载 ≤ 5s（4G）；分析 ≤ 1s     |
| 兼容性   | iOS Safari 17+、Android Chrome 120+              |
| 可访问性 | 文案全中文，专业术语配括注                       |
| 安全     | CSRF、限流、安全头、Schema 校验                  |

## 9. 风险与合规

1. **人脸数据合规**
   - MVP 阶段全部本地处理，不上传原图。
   - 若后续需云端分析，必须获得明确授权并脱敏。

2. **AI 误判风险**
   - 低置信度结果必须显式提示。
   - 避免医疗/皮肤病诊断等越界表述。

3. **审美单一风险**
   - 推荐妆容需覆盖不同风格，避免同一模板换色。

4. **CPS 合规**
   - 产品推荐需标注「广告」或「合作」时遵守《广告法》。

## 10. 调研方法建议

- **问卷调研**：针对 18–35 岁女性，收集化妆痛点、常用平台、付费意愿。
- **用户访谈**：深度访谈 5–10 名目标用户，验证「原图标注教学」价值。
- **竞品体验**：拆解小红书、美图秀秀、你今天真好看的核心流程。
- **数据埋点**：MVP 上线后追踪上传率、教程完成率、分享率验证假设。

## 11. 关键假设与待验证

| 假设                         | 验证方式             |
| ---------------------------- | -------------------- |
| 用户愿意上传自拍进行 AI 分析 | 落地页上传率 ≥ 40%   |
| 用户对本地分析信任度更高     | 分析信任度评分 ≥ 60% |
| 分区标注教学比视频更易跟练   | 教程完成率 ≥ 35%     |
| 结果卡能驱动社交分享         | 分享率 ≥ 15%         |
