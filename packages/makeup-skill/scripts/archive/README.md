# 采集 / 训练脚本归档

> ℹ️ 历史归档说明：所属模块品牌「妆语」已并入「赛博姐妹」，下文如出现「妆语」均为历史名称。

> ❄️ 已冻结 · 归档日期：2026-07-09

## 冻结原因

本目录存放的是「妆语」项目早期数据工程阶段使用的 Python 脚本，用于从
B 站、小红书等渠道采集美妆教学素材，并对素材进行标注、增强、打包成训练
数据集。这些脚本对应的功能已明确不在 MVP 范围内（详见
[`docs/scope.md`](../../docs/scope.md)），当前主分支不再运行、不再维护，
统一归档于此以保留历史与可追溯性。

- 不参与构建，不进入运行时依赖。
- 如未来需要重启数据采集，建议另开独立仓库，而非在本仓库复活这些脚本。
- 脚本的 Python 依赖（如 requests、Pillow 等）未在主项目 `package.json`
  中管理，运行前需自行准备 Python 环境。

## 脚本列表（8 个）

| 脚本                  | 用途                                       |
| --------------------- | ------------------------------------------ |
| `analyze_videos.py`   | 分析视频素材，提取关键帧与元信息           |
| `annotate_bilibili.py` | 对 B 站素材进行标注                        |
| `annotate_images.py`  | 对图片素材进行标注                         |
| `augment_data.py`     | 训练数据增强                               |
| `collect_bilibili.py` | 采集 B 站美妆视频                          |
| `collect_xhs.py`      | 采集小红书美妆内容                         |
| `pack_dataset.py`     | 打包整理好的数据集                         |
| `prepare_training.py` | 准备训练输入（格式转换 / 划分等）          |

> 说明：目录下另有若干早期实验性变体（如 `collect_xhs_mcp*.py`、
> `collect_xhs_round2.py`、`search_xhs_opencli.py`），同样已冻结，不再维护。
