# 赛博姐妹 UI 设计系统规范 V2.0

> 基于PRD V5.0深度调研，面向中国22-28岁年轻女性的AI闺蜜产品
> 设计目标：温暖、亲切、有个性，拒绝"AI味"

---

## 一、设计理念

### 1.1 设计原则

| 原则 | 描述 | 实践 |
|------|------|------|
| **闺蜜感** | 像真实朋友聊天，不是客服对话 | 圆润气泡、亲切配色、个性化头像 |
| **轻松感** | 降低使用压力，随时可聊 | 低门槛交互、温暖色调、柔和动效 |
| **安全感** | 保护隐私，不诱导消费 | 合规标识、透明付费、无情感绑架 |
| **陪伴感** | 持续记忆，长期关系 | 记忆可视化、成长轨迹、个性演变 |

### 1.2 设计关键词

```
温暖 · 活力 · 亲切 · 安全 · 有趣
```

## 七、组件规范

### 7.1 按钮

**主按钮**
- 高度：48px
- 圆角：23px（胶囊）
- 背景：渐变粉紫
- 文字：白色，16px，600字重
- 状态：hover时微抬+阴影，disabled时半透明

**次按钮**
- 高度：48px
- 圆角：23px
- 背景：品牌色10%透明度
- 文字：品牌色，16px，500字重

### 7.2 输入框

- 高度：36px
- 圆角：18px（胶囊）
- 背景：`#F5F5FA`
- 边框：无（默认）/ 品牌色2px（聚焦）
- 占位符色：`#B0B0C8`

### 7.3 消息气泡

**AI气泡**
- 背景：白色
- 圆角：16px，左下4px
- 阴影：卡片阴影
- 最大宽度：260px
- 内边距：12px

**用户气泡**
- 背景：渐变浅粉
- 圆角：16px，右下4px
- 文字：白色
- 最大宽度：260px

### 7.4 卡片

- 圆角：20px
- 背景：白色
- 阴影：卡片阴影
- 内边距：16-20px
- 交互：hover时微抬2px

### 7.5 Tab栏

- 高度：56px + 安全区
- 图标：24px
- 文字：10px，500字重
- 激活色：品牌粉
- 未激活色：`#B0B0C8`

## 九、动效规范

### 9.1 过渡时间

| 场景 | 时长 | 曲线 |
|------|------|------|
| 按钮交互 | 150ms | ease |
| 页面切换 | 350ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 弹窗弹出 | 300ms | ease-out |
| 打字动画 | 1.4s循环 | ease-in-out |

### 9.2 打字指示器

三个点依次跳动：
- 跳动幅度：4px
- 延迟间隔：200ms
- 循环时间：1.4s

## 十、页面设计规范

### 10.1 登录页

**布局结构**
```
┌─────────────────────┐
│     渐变背景区域      │  280px
│   Logo + 标题 + 副标题  │
│         ──────────│
├─────────────────────┤
│     白色圆角遮罩      │  -8px上移
│   手机号输入框        │
│   验证码输入框+按钮    │
│   登录按钮           │
│   用户协议           │
└─────────────────────┘
```

**设计要点**
- 渐变背景：粉紫渐变，营造温暖氛围
- Logo：渐变圆形背景 + 白色"赛"字
- 表单：白色遮罩向上叠压，形成层次感
- 输入框：胶囊形，图标前置

### 10.2 聊天页

**布局结构**
```
┌─────────────────────┐
│   AI身份标识栏  32px  │  渐变紫浅色背景
├─────────────────────┤
│   聊天头部  56px     │  头像+名称+状态+操作
├─────────────────────┤
│                     │
│   消息列表  flex:1   │  可滚动
│   (AI气泡+用户气泡)  │
│                     │
├─────────────────────┤
│   快捷工具栏        │  水平滚动chips
├─────────────────────┤
│   输入栏  36px       │  +按钮+输入+表情+发送
├─────────────────────┤
│   Tab栏  56px+安全区  │  聊天/工具/我的
└─────────────────────┘
```

**设计要点**
- AI标识栏：必须常驻，合规要求
- 消息气泡：AI左/用户右，清晰区分
- 打字指示器：三个跳动的点
- 快捷工具：圆角chip，可点击跳转

## 十一、响应式策略

| 断点 | 宽度 | 策略 |
|------|------|------|
| Mobile | < 640px | 全屏，1:1还原原型 |
| Tablet | 640-1024px | 居中max-width: 480px |
| Desktop | > 1024px | 手机模拟器效果 |

---

## 十二、无障碍设计

### 12.1 色彩对比度

所有文字与背景对比度 ≥ 4.5:1（WCAG AA标准）

### 12.2 触控目标

所有可点击元素最小尺寸：44px × 44px

### 12.3 焦点状态

键盘导航时显示明显焦点指示器：品牌色2px外描边
