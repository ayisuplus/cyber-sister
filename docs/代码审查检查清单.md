# 赛博姐妹 - 代码审查检查清单

> 状态：✅ 当前有效
> 使用说明：审查者在 Review 时逐项打勾，标记 ✅ 通过 / ⚠️ 有问题 / ➖ 不适用
> 每个模块独立使用，根据 PR 涉及的包选择对应清单
> 更新日期：2026-09-01（按 monorepo 结构重写模块章节，通用条目不变）

---

## 通用清单（所有 PR 必查）

### 正确性
- [ ] 代码逻辑与 PR 描述一致
- [ ] 边界条件已处理（null/undefined/空数组/超长输入）
- [ ] 异步操作有正确的错误处理
- [ ] 无 TODO/FIXME 遗留（或已有对应 issue 跟踪）
- [ ] 无调试代码残留（console.log / print / debugger）

### 安全性
- [ ] 无硬编码密钥、密码、token
- [ ] 用户输入经过校验和清洗
- [ ] 无 SQL/命令注入风险
- [ ] 敏感数据不出现在日志中
- [ ] 权限检查到位（该鉴权的接口都鉴权了）

### 可维护性
- [ ] 命名清晰、一致
- [ ] 函数职责单一（不超过 50 行）
- [ ] 无重复代码（DRY）
- [ ] 魔法数字已提取为常量或配置
- [ ] 复杂逻辑有注释说明"为什么"

### 性能
- [ ] 无 N+1 查询
- [ ] 无不必要的循环/重复计算
- [ ] 大列表/大数据集有分页或流式处理
- [ ] 前端无不必要的重渲染

### 测试
- [ ] 核心逻辑有测试覆盖
- [ ] 测试可独立运行
- [ ] Bug 修复附带回归测试

---

## `apps/api`（Express + Prisma 后端）

### 路由 & 控制器
- [ ] 所有非公开接口有 authMiddleware
- [ ] 请求参数经过 validate 校验
- [ ] 响应格式统一 `{ data, error, message }`
- [ ] HTTP 状态码使用正确
- [ ] 分页接口有 limit 上限

### 服务层
- [ ] 数据库操作使用事务（多表写入）
- [ ] 外部 API 调用有超时设置
- [ ] 错误向上抛出，不静默 catch
- [ ] 敏感操作有审计日志

### 安全
- [ ] JWT verify 指定了 algorithms
- [ ] refresh token 与 access token 有类型区分
- [ ] 限流配置合理（区分登录/普通接口）
- [ ] 密码/token 不出现在日志中
- [ ] helmet 配置完整

### Prisma 数据层
- [ ] 查询使用 select 只取需要字段
- [ ] 关联查询无 N+1（用 include 或 select 嵌套）
- [ ] 删除操作使用软删除
- [ ] 用户只能访问自己的数据（where 条件含 userId）

---

## `apps/web`（React 18 + Vite 前端）

### 组件
- [ ] 处理了 loading / error / empty 三态
- [ ] 列表渲染有稳定 key（不用 index）
- [ ] 事件监听在 useEffect cleanup 中移除
- [ ] 无内存泄漏（定时器、WebSocket、订阅）
- [ ] 大列表使用虚拟滚动（>100 项）

### 状态管理（Zustand）
- [ ] persist 不包含敏感信息（或已加密）
- [ ] 异步操作有竞态保护（请求 ID 或取消）
- [ ] 状态更新最小化（不整体替换大对象）
- [ ] 组件卸载时取消进行中的请求

### 网络请求
- [ ] 有统一的请求/响应拦截器
- [ ] token 过期自动刷新
- [ ] 错误有用户友好的提示
- [ ] 请求有 loading 状态反馈

### 样式
- [ ] 使用设计 Token 变量（不硬编码颜色值）
- [ ] 响应式覆盖所有断点（480/768/1024）
- [ ] 暗色模式适配（如已支持）
- [ ] 无 !important 滥用

---

## `packages/makeup-skill`（React 19 + Express 5 妆教模块）

### 隐私红线（最高优先级）
- [ ] 图片/视频帧分析全部在浏览器本地完成，媒体数据不外发
- [ ] 解释 API 只接受规范化特征标签 + `lookId`（不接收原始媒体）
- [ ] MediaPipe/WASM 资产按 SHA-256 校验，缺失时构建按设计失败
- [ ] 埋点不含可识别个人信息

### 前端
- [ ] 触控目标 ≥44px、键盘导航、reduced-motion 等无障碍约定保持
- [ ] 设计令牌来自 `packages/design-tokens`（不硬编码颜色值）
- [ ] 组件处理 loading / error / empty 三态

### 后端
- [ ] 输入有严格 schema 验证（防 mass assignment）
- [ ] CSRF 双重提交 Cookie / CSP / 安全头配置保持
- [ ] 敏感配置只经环境/secret 文件注入，不硬编码

---

## `packages/llm-gateway`（模型网关）

- [ ] 本地优先（llamacpp）路由默认生效
- [ ] qwen 云端降级仅在用户显式授权后启用，拒绝/撤回不影响本地链路
- [ ] 未配置本地模型时返回诚实的降级错误码（如 `LOCAL_LLM_NOT_CONFIGURED`）
- [ ] 人格定义集中在人格配置文件中维护，不散落硬编码
- [ ] 提示词层不替代服务端安全层（危机识别永远在服务端 detection 层）
- [ ] 与 `apps/api` 的接口契约变更已同步迁移全部调用方
