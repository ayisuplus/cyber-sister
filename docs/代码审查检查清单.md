# 赛博姐妹 - 代码审查检查清单

> 使用说明：审查者在 Review 时逐项打勾，标记 ✅ 通过 / ⚠️ 有问题 / ➖ 不适用
> 每个模块独立使用，根据 PR 涉及的目录选择对应清单

---

## 通用清单（所有 PR 必查）

### 正确性
- [ ] 代码逻辑与 PR 描述一致
- [ ] 边界条件已处理（null/undefined/空数组/超长输入）
- [ ] 异步操作有正确的错误处理
- [ ] 无 TODO/FIXME 遗留（或已有对应 issue 跟踪）
- [ ] 无调试代码残留（console.log / print / debugger）

### 安全性
- [ ] 无硬编码密钥、密码、token
- [ ] 用户输入经过校验和清洗
- [ ] 无 SQL/命令注入风险
- [ ] 敏感数据不出现在日志中
- [ ] 权限检查到位（该鉴权的接口都鉴权了）

### 可维护性
- [ ] 命名清晰、一致
- [ ] 函数职责单一（不超过 50 行）
- [ ] 无重复代码（DRY）
- [ ] 魔法数字已提取为常量或配置
- [ ] 复杂逻辑有注释说明"为什么"

### 性能
- [ ] 无 N+1 查询
- [ ] 无不必要的循环/重复计算
- [ ] 大列表/大数据集有分页或流式处理
- [ ] 前端无不必要的重渲染

### 测试
- [ ] 核心逻辑有测试覆盖
- [ ] 测试可独立运行
- [ ] Bug 修复附带回归测试

---

## Python ML 代码（LLM/）

### 数据管道（data_pipeline/）
- [ ] 文件读写统一使用 `encoding="utf-8"`
- [ ] 大文件使用流式/分块处理，不一次性 load
- [ ] 异常文件（空文件、格式错误）有容错处理
- [ ] 增量处理 manifest 更新时机正确（先处理成功再记录）
- [ ] 配置项有默认值和类型校验
- [ ] 日志记录处理进度和统计信息

### 训练脚本（training/）
- [ ] 超参数全部可通过命令行/配置传入
- [ ] 随机种子已固定（torch/numpy/random）
- [ ] checkpoint 保存策略合理（不会撑爆磁盘）
- [ ] 显存有 OOM 保护（try-except + 清理缓存）
- [ ] 训练数据路径不硬编码绝对路径
- [ ] 模型保存包含 tokenizer 和训练配置

### 推理服务（serving/）
- [ ] 输入文本有长度限制（防 OOM）
- [ ] 并发请求有队列/信号量控制
- [ ] 流式生成有超时和异常处理
- [ ] 模型加载失败有明确错误提示
- [ ] API 有基本认证（至少 API Key）
- [ ] CORS 策略最小化（不用 `*`）
- [ ] 错误响应不泄露模型路径/堆栈信息

---

## Node.js 后端（Agent/server/）

### 路由 & 控制器
- [ ] 所有非公开接口有 authMiddleware
- [ ] 请求参数经过 validate 校验
- [ ] 响应格式统一 `{ data, error, message }`
- [ ] HTTP 状态码使用正确
- [ ] 分页接口有 limit 上限

### 服务层
- [ ] 数据库操作使用事务（多表写入）
- [ ] 外部 API 调用有超时设置
- [ ] 错误向上抛出，不静默 catch
- [ ] 敏感操作有审计日志

### 安全
- [ ] JWT verify 指定了 algorithms
- [ ] refresh token 与 access token 有类型区分
- [ ] 限流配置合理（区分登录/普通接口）
- [ ] 密码/token 不出现在日志中
- [ ] helmet 配置完整

### Prisma 数据层
- [ ] 查询使用 select 只取需要字段
- [ ] 关联查询无 N+1（用 include 或 select 嵌套）
- [ ] 删除操作使用软删除
- [ ] 用户只能访问自己的数据（where 条件含 userId）

---

## React 前端（Agent/client/）

### 组件
- [ ] 处理了 loading / error / empty 三态
- [ ] 列表渲染有稳定 key（不用 index）
- [ ] 事件监听在 useEffect cleanup 中移除
- [ ] 无内存泄漏（定时器、WebSocket、订阅）
- [ ] 大列表使用虚拟滚动（>100 项）

### 状态管理（Zustand）
- [ ] persist 不包含敏感信息（或已加密）
- [ ] 异步操作有竞态保护（请求 ID 或取消）
- [ ] 状态更新最小化（不整体替换大对象）
- [ ] 组件卸载时取消进行中的请求

### 网络请求
- [ ] 有统一的请求/响应拦截器
- [ ] token 过期自动刷新
- [ ] 错误有用户友好的提示
- [ ] 请求有 loading 状态反馈

### 样式
- [ ] 使用设计 Token 变量（不硬编码颜色值）
- [ ] 响应式覆盖所有断点（480/768/1024）
- [ ] 暗色模式适配（如已支持）
- [ ] 无 !important 滥用

---

## 原生 Web 前端（web-app/）

### JavaScript
- [ ] 无全局变量污染（IIFE 或 ESM）
- [ ] DOM 操作使用 textContent（不用 innerHTML 拼接用户输入）
- [ ] 事件使用委托（不在循环中绑定）
- [ ] 模块间通信通过明确接口

### CSS
- [ ] 颜色/间距使用 Token 变量
- [ ] 选择器嵌套不超过 3 层
- [ ] 动画使用 transform/opacity
- [ ] 媒体查询覆盖所有断点

### 性能
- [ ] 图片有懒加载
- [ ] 首屏无阻塞资源
- [ ] 无重复的 DOM 查询（缓存引用）
