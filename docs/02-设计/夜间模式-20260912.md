# 夜间模式

> ✅ 当前有效 · 2026-09-12

入口为「会话栏 → 外观设置 → 外观」；手机端先点聊天页左上角菜单展开会话栏。提供日间、夜间、跟随系统三个选项。首次打开跟随系统，手动选择保存在本机浏览器；刷新和退出账号后仍保留。恢复跟随系统时立即采用当前系统配色，并响应后续系统变化。

## 实现边界

- 配色唯一来源仍是 `packages/design-tokens/tokens.css`，通过 `html[data-theme="dark"]` 覆盖语义令牌。深墨绿页面、层次化卡片、浅鼠尾草主操作统一覆盖聊天、工作桌面、设置、工具与登录界面。
- `index.html` 在应用与样式加载前解析偏好；`themeStore.js` 管理本机选择、系统变化、跨标签同步与监听清理。原有 `appearanceStore.js` 继续负责账户私有背景，不混入主题状态。
- 同步设置原生控件的 `color-scheme`。本地存储不可用时仍可在本次打开期间切换；此时不保证刷新后记住选择。
- 装饰用聊天氛围图、工作视频和纸贴降低夜间亮度；用户照片、摄像头、试妆画布保持原色。工作视频继续沿用已制作素材与现有暂停、减少动态效果、省流量策略。手机工作标题遮罩加强，经期摘要使用深色大卡片，避免局部亮面刺眼。
- 已完成日程和暂停提醒保留灰化语义色、删除线和状态文案，取消整行透明度；经期卡片说明文字也取消透明度，避免浅色和深色下小字失去对比度。

## 验证

- 前端全量单元测试：81 个文件、659 项通过，其中主题启动、手动/系统优先级、跨标签、存储异常、退出账号和键盘选择均有专项覆盖。
- TypeScript 检查与生产构建通过。专项 ESLint 无错误；聊天、试妆与提醒面板保留原有复杂度警告，衣橱页保留构建分块体积警告。
- 独立对比度复核：夜间文字、状态和主色在九种语义表面上的 81 组配对最低 5.61:1；聊天用户气泡渐变端点最低 5.34:1；反色文字在操作/状态背景上的最低值 8.81:1。上述是色值计算，实际覆盖图片的文字仍须浏览器检查。

- 浏览器最终回归 `run-05`：桌面与手机共 6 项测试通过，包含从真实会话栏/手机抽屉进入外观设置、选择保持、系统变化、聊天气泡、四个工作主题、日程表单、暂停提醒、经期、登录以及 320px/横屏场景。24 次 axe 扫描未发现 serious/critical 问题，未发现横向溢出。
