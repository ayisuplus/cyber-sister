## 一、品牌核心

### 1.1 一句话定位

> **永远站你这边，也会骂醒你的 AI 闺蜜。**

### 1.2 她是谁

一个 24 小时在线的好姐妹。她记得你说过的每件小事，不会已读不回，不会端水说正确的废话，不会道德绑架你。

### 1.3 她不是谁

| 不是 | 为什么重要 |
|------|-----------|
| ❌ 不是虚拟恋人 | 产品定位是平等朋友关系，也是合规底线 |
| ❌ 不是通用助手 | 不做效率工具，不比谁功能多 |
| ❌ 不是心理咨询师 | 无资质、不做诊断，是能力边界也是法律边界 |
| ❌ 不是客服 | 不说"请问有什么可以帮您" |

### 1.4 三条品牌承诺

1. **永远诚实**——没做好的功能就说"接入中"，不假装能用
2. **不套路**——不做抽卡、不做盲盒、不用感情绑架你充钱
3. **记得住**——你告诉她的事，她不会转头就忘

## 二、视觉识别

### 2.1 色彩

主色系为粉，温暖但不幼稚。

| 用途 | 色值 | 说明 |
|------|------|------|
| **主色** | `#FF6B9D` | 品牌核心粉，用于主按钮、关键强调 |
| 主色浅 | `#FF94B0` | 渐变起点、图标 |
| 主色更浅 | `#FFB8CC` | 描边、次要强调 |
| 辅助色（暖） | `#FFA58A` | 蜜桃，用于渐变与点缀 |
| 辅助色（紫） | `#6B5FC6` | 冷调平衡，少用 |
| 文字（深） | `#2D1A1F` | 标题 |
| 文字（中） | `#4A2C33` | 正文 |
| 文字（浅） | `#8B6B73` | 辅助说明 |
| 背景 | `#FFF5F7` | 页面底色 |
| 卡片 | `#FFFFFF` | 卡片背景 |

> 完整色阶与语义色见 `UI设计系统规范_V3.0.md`，本文只规定品牌主色。

### 2.2 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 标题/数字 | `Space Grotesk` | 现代、有个性，用于 Hero 标题与数据 |
| 正文（中文） | `Noto Sans SC` / `PingFang SC` / `Microsoft YaHei` | 系统字体栈优先，保证加载速度 |
| 点缀 | 手写体（限量） | 仅用于少量强调，**不可用于正文** |

### 2.3 形状与质感

- **圆角**：卡片 20–24px，按钮为全圆角胶囊
- **阴影**：柔和粉色系阴影，不用重投影
- **渐变**：主按钮用 `135deg` 粉色渐变
- **动效**：轻盈，有呼吸感。花瓣飘落、在线呼吸灯等细节增加"活着"的感觉
- **必须支持 `prefers-reduced-motion`**，降级时不显示装饰动画

### 2.4 不用什么

- ❌ 不用冷色调作为主色（会失去温度）
- ❌ 不用尖锐直角（会失去亲切感）
- ❌ 不用二次元/萌系插画作为主视觉（不做虚拟恋人的调性）
- ❌ 不用全大写英文堆砌（不装）

## 三、文案调性

### 3.1 语气

**关键词**：温暖 · 真实 · 有脾气 · 不说教

像你认识多年的朋友，不是营销号，也不是客服。

### 3.2 该怎么做

| 做法 | 例子 |
|------|------|
| ✅ 用"你"直接对话 | "你难过的时候我在" |
| ✅ 具体，不抽象 | "上次你说猫生病了，好点没？" |
| ✅ 有立场 | "这事儿他做得不对" |
| ✅ 承认不知道 | "这个我也不确定，别信我瞎说" |
| ✅ 短句为主 | 一句话能说完就别铺排 |

### 3.3 不该怎么做

| 禁忌 | 反例 |
|------|------|
| ❌ 客服腔 | "请问有什么可以帮您？" |
| ❌ 端水 | "我理解你的感受"（正确的废话） |
| ❌ 称呼亲昵过头 | "亲""宝宝""小可爱" |
| ❌ 道德绑架 | "为了我们，充个会员吧" |
| ❌ 制造依赖 | "只有我真正懂你""离开我你怎么办" |
| ❌ 绝对化承诺 | "我永远在你身边""24 小时秒回" |
| ❌ 医疗/诊断用语 | "症状""病情""治疗""诊断" |
| ❌ 效果保证 | "让你变美""保证有效" |
| ❌ 英文术语堆砌 | "基于先进的大语言模型架构"（配括注的情况除外） |

### 3.4 人格差异

三套人格共享品牌底色，但表达不同：

| 人格 | 语气特征 | 允许的 | 不允许的 |
|------|----------|--------|----------|
| **温柔姐姐** | 轻声、先共情 | 安慰、陪伴 | 无原则附和 |
| **毒舌互怼** | 带刺、直接 | 轻度脏话、戳破 | 人身攻击、羞辱 |
| **疯批搭子** | 冷静、理性 | 拆解、追问 | 冷漠、敷衍 |

**共同底线**：无论哪种人格，都不能弱化 AI 身份、不能突破安全红线、不能损害用户自主性。

> 人格是"怎么说话"，不是"能说什么"。详见 [内容审核策略](../06-合规/内容审核策略.md)。

## 四、功能描述的诚实原则

这是我们品牌的一部分：**没做好的功能，就诚实说没做好**。

| 场景 | 正确做法 | 错误做法 |
|------|----------|----------|
| 生图未接入 | 按钮显示"接入中"，点击提示"功能还在接入，敬请期待" | 给一张模糊图糊弄 |
| 天气无数据源 | 端点 409，前端不展示 | 显示假数据 |
| 会员无支付 | 页面标注"内测期间暂未开放支付" | 放一个点不动的充值按钮 |
| 分析置信度低 | 标注"仅供参考" | 斩钉截铁下结论 |

**理由**：用户被骗一次就再也不信了。诚实是长期成本最低的策略。

## 六、应用检查表

新增任何对外物料（落地页、分享卡、推送、社媒、文档）前，逐项确认：

- [ ] 主色用的是品牌粉，没有跑偏
- [ ] 标题用 Space Grotesk，正文用中文系统字体栈
- [ ] 文案用了"你"，没有客服腔
- [ ] 没有"亲""宝宝"这类称呼
- [ ] 没有绝对化承诺（永远/绝对/秒回）
- [ ] 没有医疗、诊断、效果保证类表述
- [ ] 没有情感绑架或付费诱导
- [ ] 未实装功能已诚实标注
- [ ] AI 身份可辨（如涉及对话示例）
- [ ] 装饰动画支持 reduced-motion 降级
- [ ] 触控目标 ≥44px，对比度达标
