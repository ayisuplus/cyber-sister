# 手帐小装饰

> 状态：✅ 当前有效（2026-09-23）。裁定见路线图 C18。素材的来源记录在 `apps/web/public/design-assets/decor/decor-assets.json`；偏好小实验的做法见[装饰偏好小实验](../04-开发/装饰偏好小实验.md)。

## 为什么加

产品负责人的判断：核心哲学是简约，但简约不等于光秃秃，女孩子喜欢小装饰。

这份文档把「加什么、加在哪、加多少」都落到研究上。论文可以直接引用这里的设计取舍；取舍对不对，由偏好小实验来检验。

## 研究依据

每一条研究都对应下面的一条规则。

1. **手工效应：手做的东西「装着爱」。**[Fuchs 等 2015](https://journals.sagepub.com/doi/10.1509/jm.14.0018) 发现，被告知是手工做的东西更招人喜欢，主要原因是人觉得它「装着爱」。信纸上的手写字是同一个道理，所以装饰要手绘、带一点不完美，不用规整的矢量图标。
2. **一点可爱能带来正面情绪，但可爱放在物件上。**[Nittono 等 2012](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0046362) 发现，看过可爱的图片后，人做需要专注的事更细致，作者的解释是可爱引发了正面情绪。但[婴儿图式研究](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4393829/)也发现，被画得幼态的成年人会被看成弱、天真，UI 规范 §4 也禁止幼态化。所以可爱只放在小猫、花草这些物件上。
3. **圆润、自然的形状更安心。**[Bar & Neta 2006](https://journals.sagepub.com/doi/10.1111/j.1467-9280.2006.01759.x) 发现人偏好弧线，尖角会引起威胁感。[亲自然设计的研究](https://www.nature.com/articles/s41598-025-23224-3)显示植物元素能降低压力。压花、叶子正好配现在的鼠尾草绿。
4. **心理类场景要克制，这一条最要紧。**
   - [Garrido 等 2024](https://journals.sagepub.com/doi/10.1177/14604582241295948)：年轻人给心理类 App 挑设计时，偏好干净、有质感、用色克制，觉得「心理健康是严肃的事」。全文没有打开，依据的是摘要层面的信息。
   - [Smashing 2026](https://www.smashingmagazine.com/2026/07/designing-distressed-users-mental-health-apps-ui/)：难受的人觉得明亮欢快的颜色刺眼；不能在难过时庆祝；俏皮元素不能跟求助入口抢注意力。
   - 所以装饰只放在页边、静止不动，危机那一页一枚都不贴。
5. **手帐本身就是年轻女性的「慢治愈」。**
   - [千瓜 2025「兴趣生活」报告](https://www.itopmarketing.com/uploads/soft/20250709/1752058856.pdf)：小红书女性用户约 72%，以 95 后、00 后为主，手工长居热榜，被称为「慢治愈」。
   - [田园风（cottagecore）](https://www.cutestudies.com/compendium/cottagecore)也是靠可爱加田园意象给人安慰。
   - 纸胶带、压花、邮票、火漆印，都能直接接上现有的「本子」设定（UI 规范 §9）。
6. **不走「涂成粉色」的路。**
   - 「涂成粉色、再缩小一号」式的性别化设计一直被批评（[van Tilburg 等 2015](https://onlinelibrary.wiley.com/doi/full/10.1002/mar.20789)）；刻板印象还会让设计重外观、轻功能（[2026](https://link.springer.com/article/10.1007/s00163-026-00475-3)）。
   - 「女性偏爱粉紫」本身也有争议：[Hurlbert & Ling 2007](https://www.sciencedirect.com/science/article/pii/S096098220701559X) 在英国和中国被试里都看到这个倾向，[Taylor 等 2013](https://pubmed.ncbi.nlm.nih.gov/23148465/) 在纳米比亚的 Himba 人里没有看到。
   - 所以不换粉色主题，最多加一点杏色、灰玫瑰点缀，装饰也永远不代替功能。
7. **自己能选，会更珍惜。**[Franke 等 2010](https://ideas.repec.org/a/inm/ormnsc/v56y2010i1p125-140.html) 提出了「我自己设计的」效应。[Moss & Gunn 2009](https://www.tandfonline.com/doi/full/10.1080/01449290802332662) 显示审美有性别差异，女性更偏好女性做的设计，但人与人之间差别也很大。所以装饰要给开关。

## 规则

1. 手绘线稿，跟封面插画一个路子：深藏青细线，填色是低饱和的鼠尾草绿、奶油、杏色，外加一点灰玫瑰。
2. 植物为主。小猫只出现在来信的邮票上；封面那只是原有插画里的，不另加。
3. 只放在页边：封面、日期旁、页码那一行、来信信头。不压正文，不贴在她说的话旁边。
4. 全部静止：没有动画，没有庆祝效果。原有的枝叶慢动不变。
5. 每页最多一枚，按页码固定，刷新后不变。出现危机干预的那一页一枚都不贴，危机弹窗不受影响。
6. 夜间自动调暗；SVG 小画跟着铅笔灰变色。
7. 全部是纯装饰：`alt=""`、`aria-hidden`，点不到，读屏也读不到。设置里「小装饰：没有」时，一个都不显示。

## 加了什么

| 位置 | 装饰 | 实现 | 什么时候不出现 |
| --- | --- | --- | --- |
| 封面 | 拱窗顶上一段纸胶带；左下角一枝压花雏菊；问候语前一个时段小画（深夜是弯月） | `ChatPage.jsx` 的 `CoverPage`；纸胶带用 CSS 画 | 装饰关掉时 |
| 日期行 | 「9月23日 · 凌晨」前的时段小画：晨、昼、昏、夜四种 | `LetterEntry.jsx`，时段来自 `letterDate.js` 的 `dayPhase` | 装饰关掉时 |
| 页码那一行 | 右边一枚植物贴纸，6 枚按页码轮换（雏菊、勿忘我、鼠尾草、银杏、三叶草、薰衣草） | `LetterPad.jsx` 与 `Decor.jsx` 的 `pageStickerFor` | 封面那一页；有危机干预的那一页；装饰关掉时 |
| 来信 | 对话里来信便签的右上角一枚火漆印；「她」页看信时，信头一张小猫邮票、信尾一枚火漆印 | `HerNudges.jsx`、`LetterView.jsx` | 装饰关掉时（别的便签本来就不压） |

- **共用组件**：`apps/web/src/components/letter/Decor.jsx` 里有素材清单、`Sticker`、`DayPartDoodle`、`WashiTape`。样式在 `globals.css` 的「手帐小装饰」一节。
- **危机那一页怎么判断**：危机干预那一段带 `data-quiet`，`usePagedLetter` 量版面时算出它落在第几页。一段话被分到两页的，两页都算。
- **开关**：设置 → 外观 →「小装饰：有 / 没有」，默认有。选择存在这台设备的 `amie-decor` 里，写到 `<html data-decor>` 上。样例图不受开关影响，关掉之后也看得到「有」是什么样子。
- **夜间**：贴纸压暗一些（`brightness .82`、`saturate .85`），纸胶带降到 55% 不透明。

## 素材怎么来的

- **生成**：本机 ComfyUI 0.37.0 加 Qwen-Image 2.1，直接出透明底 PNG（1024×1024，30 步，euler / simple，cfg 1）。提示词用固定的风格前缀，每次只画一件物件；原文和 seed 都记在来源记录里。
- **挑选**：8 件物件各出 3 个 seed，拼成风格板，由作者逐件挑选。选中的是雏菊 2002、勿忘我 1001、鼠尾草 3003、银杏 2002、三叶草 2002、薰衣草 2002、火漆印 1001、邮票 1001；落选的 16 张也记在来源记录里。
- **后期**：`tools/decor/process_stickers.py build`，用 ComfyUI 自带的 Python 跑，不另装依赖。依次做这几步：
  1. 透明度低于 16 的归零，去掉底雾；
  2. 半透明边缘换成相邻不透明像素的颜色，去掉色边；
  3. 裁掉多余的透明边；
  4. 描一圈约 2.5px 的白色模切边；
  5. 缩到显示尺寸的 2 倍，存成 WebP。
- **体积**：8 件一共 20.5KB。单件不超过 20KB、整套不超过 150KB，有单测核对；单测也核对清单、来源记录和文件三者的宽高、字节数、sha256 是否一致。
- **许可**：Qwen-Image 2.1 用的是 Qwen Research License，只允许非商业用途，对生成的图没有另加限制。这里是课程作业和论文原型，属于非商业用途。**以后要是商用，这批贴纸必须换掉或另取授权。**
- **复现**：
  1. 在 ComfyUI 里跑作者本机的「Qwen-Image 2.1 文生图」工作流，得到候选图，逐张记进 `runs.jsonl`；
  2. `process_stickers.py board --runs <runs.jsonl> --out <联系表.png>` 拼联系表；
  3. `process_stickers.py build --runs <runs.jsonl> --pick 物件=seed ...` 生成素材和来源记录。

## 踩过的坑

- **分栏会裁掉伸出去的部分**：便签正好落在一页最上面时，绝对定位伸出便签上沿的火漆印，会被分栏的上沿裁掉。所以火漆印改成浮在便签里，只借用便签自己的内边距。
- **透明底不干净**：模型出的透明底下面留着一层肉眼几乎看不见的紫色底雾，半透明的边缘也会渗进紫色。靠后期的去雾和去色边处理掉。
- **comfy-cli 误报**：comfy-cli 1.20 的客户端检查不认 `TextEncodeQwenImage21` 参考图输入的下限是 0，把纯文生图判成非法；服务器本身允许。所以只用它把界面格式转成接口格式（`comfy run --print-prompt`），再直接提交给 ComfyUI 的 `/prompt`。

## 不做

- 不换粉色主题。
- 不加动画和庆祝效果。
- 信纸页上不放小猫。
- 暂不做「用户自己贴贴纸」：研究支持（「我自己设计的」效应），可以留作以后。
- 不动危机弹窗。
- 手记、读书、设置这些页面不加装饰。
