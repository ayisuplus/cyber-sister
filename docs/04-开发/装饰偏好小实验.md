# 装饰偏好小实验

> 状态：✅ 当前有效（2026-09-23）。材料已经能一键生成，还没有请人来评；「结果」一节先空着。装饰的设计与研究依据见[手帐装饰](../02-设计/手帐装饰.md)，裁定见路线图 C18。

## 要回答什么

同一个画面，装饰「没有 / 少量 / 较多」三档，年轻女性怎么看？

- **H1**：「少量」比「没有」更讨喜，也更让人觉得被用心对待（手工效应），平静感不下降。
- **H2**：「较多」在倾诉的那一页上，比「少量」更显幼稚、更干扰阅读（心理类场景要克制）。
- **H3**：夜间版比日间版更让人平静（深夜场景）。这一条是探索性的。

「少量」就是产品里实际的样子。「较多」只为实验存在：截图时额外叠加，每页多两枚植物、信纸上也放小猫邮票、多一段胶带，而且都贴在空白处、不压字。比的是「多」本身，不是「挡住字」。

## 材料

一条命令生成（先构建，再截图）：

```bash
pnpm --filter cyber-sister-client study:decor
```

- **一共 18 张**：3 个画面（封面、倾诉中的一页、收到来信的一页）× 3 档装饰 × 日间、夜间两套。
- **截图条件**：手机尺寸（390×844，2 倍图），时间固定在北京时间 2026-09-23 01:40，对话内容固定。倾诉页截的是第一页，看得到日期行、你说的和她回的。接口全部用桩，不联网。
- **输出**：在 `apps/web/study-results/decor-study/`，这个目录不进仓库。特意不放在 `test-results/`，因为那里每次跑 e2e 都会被 Playwright 清空。里面有：
  - `named/`：按条件命名，给作者看；
  - `blind/`：随机编号 P01–P18（种子固定，每次生成的编号都一样），给被试看；
  - `key.json`：编号和条件的对照表，外加三档的出场顺序。
- **内容安全**：倾诉页的内容是「明早要汇报、睡不着」这种日常压力，材料里没有任何危机内容。

## 被试与流程

- **被试**：6–10 位年轻女性同学或朋友，成年、自愿，不收集可识别身份的信息。
- **设计**：被试内设计，每个人都看完 18 张。
- **分组**：18 张分成 6 组，每组是同一画面、同一主题的三档（例如「倾诉页 · 夜间」的没有、少量、较多）。
- **组的顺序**：每个人随机，问卷平台的「题目随机」可以做到。一半人先看夜间，一半人先看日间。
- **组内三档的顺序**：按 3×3 拉丁方轮换，第 1、4、7 位用第 1 行，第 2、5、8 位用第 2 行，第 3、6、9 位用第 3 行（见 `key.json` 的 `orders`）：
  - 第 1 行：没有 → 少量 → 较多
  - 第 2 行：少量 → 较多 → 没有
  - 第 3 行：较多 → 没有 → 少量
- **怎么看**：在自己的手机上看原尺寸的图，不放大，每张不限时间。大约 10–15 分钟。

### 开始前念给被试的话（知情同意）

> 这是我课程作业（也可能写进毕业论文）里的一个小调查：看 18 张聊天界面的截图，给每张打几个分。界面里的对话都是编的，不需要你讲自己的事。问卷匿名，不收集你的姓名、手机号；结果只以汇总的形式出现在作业或论文里。任何时候都可以停下，不用说明理由。愿意的话我们就开始。

### 问卷题目

题目可以直接粘进问卷星或腾讯问卷。

**每一张图**：先放图（用 P01 这样的编号，不要写条件），再放 5 道 7 级量表题，1 表示非常不同意，7 表示非常同意：

1. 我喜欢这个画面。
2. 看着这个画面，我心里是平静的。
3. 这个画面让我觉得自己被用心对待。
4. 这个画面显得有点幼稚。
5. 画面上的东西干扰了我读上面的字。

**每一组三张看完以后**：

6. 刚才这三张里，你最喜欢哪一张？（单选：第一张 / 第二张 / 第三张）
7. 为什么？用一句话说说。（填空，选填）

**最后**：

8. 你平时用手帐、贴纸、胶带这类东西吗？（从不 / 偶尔 / 经常）
9. 深夜心里难受、想找人说说的时候，你希望聊天界面是什么样的？（填空，选填）

## 分析

- **量表题**：同一组里的三档，每一项做 Friedman 检验；有显著差异的，再两两做 Wilcoxon 符号秩检验，用 Holm 法校正。报告中位数和四分位距。样本小，重点看方向是否一致，不过度解读 p 值。
- **最喜欢哪一张**：数每一档被选中的次数；看「少量」被选中的比例是否高于三分之一（二项检验）。
- **开放回答**：按主题归类，例如温暖、幼稚、乱、安静、像手帐、看不清字，每类摘一两句原话。
- **探索性**：按第 8 题的手帐使用频率分组，看偏好有没有差别，只做描述统计。
- **H3**：同一画面、同一档，比较日间和夜间的平静分。

## 局限

- **人少、不是随机抽的**：样本小，被试是方便抽样来的同学、朋友，结论只能算初步证据。
- **看截图不等于真用**：没有翻页、没有真的在倾诉，看久了的感受测不到。
- **「较多」是人为叠加的**：它只代表「多了一些」，不代表其他某种精心设计的丰富版本。
- **可能有期待效应**：被试知道这是「给女生做的 App」，打分可能偏向讨好。材料只写编号、不写条件，能缓解一部分。
