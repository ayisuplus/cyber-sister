# 模型连接、对话归档与设置

> 状态：✅ 当前有效 · 2026-09-12

## 模型配置

聊天网关使用 OpenAI 兼容协议，供应商槽名 `qwen` 不限定实际供应商。启动 API 时需同时加载 `GATEWAY_QWEN_BASE_URL`（含 `/v1`）、`GATEWAY_QWEN_MODEL`、`GATEWAY_QWEN_API_KEY_FILE`。密钥继续从仓库外文件读取；不要把值写进环境示例或前端。

仅保留密钥文件不足以完成接入。旧的 `LLM_API_URL` / `LLM_MODEL` 不会配置现有云端网关。修改进程环境后需重启 API。普通聊天仍受用户云端同意状态控制；工作模式保持固定模拟，不因聊天模型恢复而启用真实推理。

`GET /api/llm/status` 读取服务端配置和当前用户的同意状态，不主动请求供应商。设置页显示“已配置”而非声称持续在线，提供刷新状态、允许/撤回聊天授权以及保存失败重试。

## 对话归档

迁移 `20260912120000_conversation_archive` 为 `conversations` 新增可空的 `archived_at` 与用户/归档/更新时间索引。旧对话默认仍在主列表。归档与恢复仅修改会话元数据，不删除消息和照片；导出包携带 `archivedAt`。现有导入功能仍不导入对话。

| 接口 | 行为 |
| --- | --- |
| `GET /api/chat/conversations` | 默认只列未归档的会话 |
| `GET /api/chat/conversations?archived=true&page=1&limit=20` | 分页列出当前用户的归档；显式 `false` 查询未归档 |
| `PATCH /api/chat/conversations/:id/archive` | JSON `{ "archived": true }` 归档，`false` 恢复；返回 `{ "success": true, "archived": true/false }` |
| `GET /api/chat/conversations/:id?page=1&limit=50` | 读取本人会话，包括归档会话；第一页为最新消息，后续页向前翻阅 |

归档请求严格验证布尔类型，并在写入条件内绑定登录用户；他人或不存在的会话统一返回 404。归档会话发起新消息请求返回 409 / `CONVERSATION_ARCHIVED`，须恢复后继续。正在发送消息时前端禁用当前会话的归档按钮；归档不取消其他设备已经开始的请求。

前端 `/chat/archives` 提供查看记录、加载更多归档、加载更早的消息和恢复操作。归档后主列表即时移除；侧栏操作同步刷新已经打开的归档页。失败保留原列表，注销后的迟到响应不会写回新账号状态。

## 设置入口

桌面侧栏、手机会话抽屉均提供“对话归档”和“设置”；聊天页右上角也有设置图标。设置页汇集聊天模型授权、日夜外观、提醒与关怀开关、日程管理、资料与装扮、记忆管理及退出登录。外观沿用本机偏好，记录和授权仍经现有服务端 API。

## 验证

覆盖参数错误、跨用户访问、普通/流式消息的归档限制、归档恢复保留消息、列表与详情分页、网络失败重试、注销后的迟到响应，以及设置保存失败保留原值。真实 PostgreSQL 集成测试使用独立临时数据库。

本地预览的模型完成过最小请求与浏览器流式回答验证；测试对话完成归档、读取及恢复。数据库迁移前已在仓库外保存本地备份。工作模式仍处于模拟阶段。
