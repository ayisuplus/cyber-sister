# Amie UI 设计系统规范 V3.0

> 状态：本地优先基础版实施基线  
> 更新日期：2026-09-26（§2.1 主题色，路线图 C25）；2026-09-23（§4、§9 加手帐小装饰，路线图 C18）；2026-09-16（§5、§6 随功能收拢更新，新增 §8 信息架构）；2026-09-15（§2 色板对齐 09-09 鼠尾草换肤；§3 动效条款与 §7 静谧层随界面质感升级更新）

## 1. 设计立场

产品首先传达“私密、轻松、像闺蜜一样自然”，不以模型参数、推理能力或技术感作为主视觉卖点。界面必须持续说明 AI 身份与回复来源，但不把用户置于配置术语和供应商术语中。

四项原则：

- **隐私可见**：本地处理、云端备用、图片不上传等状态使用稳定文字和来源标签，不只依赖颜色。
- **柔和但清晰**：低饱和色只承担背景与分区；正文、按钮、焦点和危机状态使用独立高对比语义色。
- **像朋友而非客服**：中文短句、圆润层级、克制动效；不使用虚假的在线状态、真人暗示或情绪绑架。
- **能力不冒充上线**：虚拟试衣间、虚拟化妆间等未实现模块只能展示“规划中”，不得提供伪上传、伪生成或伪支付。

### 2.1 主题色（2026-09-26，路线图 C25）

设置 → 外观 →「主题色」：六套预设（鼠尾草、樱花粉、蜜桃、奶茶、雾霾蓝、薰衣草）或「自己调」一个色相。是这台设备的偏好（`amie-palette`），和日夜模式一样由 `index.html` 的启动脚本在样式加载前贴上，打开时不闪默认色。

- **鼠尾草就是上表**：选它不生成、不覆盖任何变量。
- **其余由一个色相生成**（`apps/web/src/features/palette.js`）：每种用途的 OKLCH 明度与饱和度固定、只换色相，日间夜间各一套；覆盖粉彩（除米杏）、主操作与悬停、信息/焦点、三级文字、页面与弱分区表面、四级边框、「你」的气泡与两层环境光，夜间另覆盖卡片、输入框与反白字。
- **不随主题色变**：本地成功、警告、危险三个语义色；信纸、三种墨色与本子封皮；阴影与遮罩；米杏粉彩与纸胶带；压花、火漆印等贴纸（图片）。
- **对比度由规则保证**：单测对每套预设与 0–359° 的每一度核对三级文字、主操作色与语义色在各级表面上、以及按钮上的反白字，全部 ≥ 4.5:1（最紧的是日间淡底上的主色字，5.02）；端到端再用 axe 在设置、「她」页、对话页上日夜各查一遍。

## 3. 形态、排版与动效

- 正文字体只使用系统中文字体栈，不请求 Google Fonts 或其他第三方字体服务。唯一的例外是对话信纸上的手写字：霞鹜文楷·屏幕版 GB（OFL），随应用自托管、按 unicode-range 切块只加载用到的字（2026-09-22，见 §9）；展示标题仍只用系统字体栈（见 §7）。
- 正文默认不小于 14px；辅助说明不小于 11px，并保证语义色对比。
- 控件最小触控尺寸 44×44px；表单必须有可见标签，图标不能替代名称。
- 卡片圆角以 30px 为基线，控件约 18px，底部面板 34px（`--cs-radius-card/control/sheet`）；对话不再用气泡，写在信纸上（见 §9）。阴影低透明、分层柔和，不做高亮霓虹。
- 动效只减速、不回弹：交互反馈 200–320ms；入场 420–640ms；环境循环 ≥8s，且只动 transform/opacity。必须响应 `prefers-reduced-motion`（环境动效静止、入场延迟归零），核心流程不依赖动画完成。
- 手机全屏优先；桌面可使用居中的手机内容框，但不得限制浏览器缩放。

## 4. 插画与角色资产

插画采用低饱和粉彩、留白、柔和轮廓和明确友善表情。人物呈现避免单一审美模板、幼态化、性暗示、肤色刻板印象和“完美变美”暗示。AI 形象必须保留非真人线索。

资产进入主流程前必须完成：来源/授权记录、人工审看、移动端裁切、替代文本、体积优化。纯装饰图使用空 `alt`；承载状态的图必须由邻近文字完整表达含义。不得为填充页面临时下载运行时图片。

当前基础版复用仓库内已跟踪的 Logo、AI 头像与聊天空状态插画。后续虚拟试衣和虚拟化妆资产仍复用本规范，不自动获得上传用户照片的权限。

**手帐小装饰（2026-09-23，路线图 C18）**：页边的压花、叶子、火漆印、邮票，以及日期旁的时段小画。植物为主，小猫只出现在来信的邮票上。贴纸由本机 ComfyUI 生成，来源与许可记在 `apps/web/public/design-assets/decor/decor-assets.json`。所用模型是 Qwen Research License，只允许非商业用途，商用前必须换掉或另取授权。全部是纯装饰（`alt=""`、读屏隐藏），设置里可以关掉。依据与规则见[手帐装饰](02-设计/手帐装饰.md)。

## 5. 核心页面合同

- **登录**：只显示手机号、固定内测码、登录状态与隐私范围；没有“获取验证码”伪交互。
- **对话**：只有一种对话，写在信纸上（§9）。AI 身份常驻；只标例外来源（本地安全模板）；模型失败保留输入。页头只放她的名字、AI 标识与设置，不放人格徽章或模式切换；空白对话只有问候与最多 4 个开场。
- **她**：说话方式三选一，切换明确“下一条生效”；记忆由用户显式创建、编辑、删除与清空，待确认的理解由用户决定是否算数。
- **安排**：一处列出所有定时安排，按今天 / 接下来 / 重复 / 已暂停 / 已完成分组；交给她做的事如实标注执行未接通。
- **设置**：形象、外观、唯一的聊天模型授权开关、关怀、数据与迁移；从未真正投递的开关不得出现。
- 已下线：本地模型管理（2026-09-07）、妆教（2026-09-05）、发现页（2026-09-15 并入导航）。

## 6. 扩展与验收

新入口只在 `apps/web/src/features/registry.js` 登记（§8），拥有真实路由、隐私合同、服务端白名单输入与 E2E 后才能加入；优先并入已有入口的页签，而不是新开一个入口。独立模块复用共享令牌、主应用 access token 和主 API 模型路由。

每次发布至少检查键盘顺序、焦点可见、对话框焦点管理、live region、44px 触控、200% 缩放、reduced-motion，以及 axe critical/serious。通过这些门禁不等同于正式 WCAG 认证。

## 7. 静谧层（2026-09-15）

目标是让用户打开 Amie 时心能静下来：少即是静、慢即是柔、柔软要有质感。令牌在 `packages/design-tokens/tokens.css`，样式在 `apps/web/src/styles/globals.css`。

- **动效令牌**：`--cs-ease-calm`（长尾减速）、`--cs-ease-breathe`（正弦往复）；`--cs-dur-quick/soft/settle` 为 200/320/560ms，`--cs-dur-breath` 为 8s（4 秒吸、4 秒呼）。入场动画一律 `fill-mode: backwards`，结束后不残留 transform/filter。
- **环境光（晨雾 / 月下森林）**：`AmbientMist` 在应用主区和登录页铺三团 `--cs-glow-1/2/3` 径向光，48–64s 往复漂移（手机两团），只动 transform，空闲时不触发布局。叠加 `--cs-grain-opacity` 的纸张颗粒（SVG 噪声平铺）。设置自定义主页背景时不渲染。
- **材质**：`.glass-bar`、`.glass-strong`、`.glass-mist` 为半透明底加背景模糊，不支持时退回实色。阴影统一为分层柔影（`--cs-shadow-soft/float` 等）；（2026-09-22 起对话不再用气泡，见 §9。）
- **字体栈**：`--cs-font-display`（Palatino / Georgia / 思源宋体等，刻意不含 SimSun）用于品牌字标与展示标题；`--cs-font-hand` 2026-09-22 起指向自托管的霞鹜文楷·屏幕版，用于对话信纸（§9）和一两句手写点缀，如时段问候、登录标语；字体没到之前退回系统楷体。
- **品牌标识**：`BrandMark` 由落地页同款单叶线稿加斜体衬线 "Amie" 组成，用于侧栏与登录页。
- **聊天页**：2026-09-22 起改为信纸，见 §9；流式末尾的呼吸墨点与空白会话的枝叶装饰保留。
- **不变的边界**：AI 身份常驻条、例外来源标签（本地安全模板等）、危机弹窗文案与对比度要求（≥4.5:1）不因质感调整而弱化；危机弹窗入场缩短到 240ms。2026-09-21 按路线图 C9 裁定，普通云端回复不再逐条标「云端模型」（同意时已说明，页头常驻 AI 身份），只标例外。

## 8. 信息架构（2026-09-16）

一件事只有一个入口，同一批功能只有一种组织方式。导航由 `features/registry.js` 这一份注册表驱动，`AppNav` 放在会话列表底部，侧栏与手机抽屉共用。

| 入口 | 路由 | 内容 | 网页版 |
| --- | --- | --- | --- |
| 对话 | `/chat` | 唯一的会话类型；本地客户端可附文件、交给她后台执行 | ✅ |
| 她 | `/her` | 说话方式、她的节奏、她记得的你（已记住 / 待确认 / 关系） | ✅ |
| 安排 | `/tools/schedule` | 定时安排：一次、每天、每周、每月、每年 | 本地 |
| 手记 | `/tools/notes` | 日记 / 读书 / 来信三个页签 | 本地 |
| 经期 | `/tools/period` | 经期记录与预测 | 本地 |
| 装扮 | `/tools/style` | 衣柜 / 化妆间两个页签：你自己的收藏（2026-09-21 起不再做生成） | 服务器（照片在 API 数据卷） |
| 花草 | `/tools/garden` | 花草图鉴：拍一张，她认一认、讲一讲，收不收由你；标本签式卡片，名字手写（2026-09-26，路线图 C26，改动 C9「不再加入口」） | ✅（认一认要云端同意；照片收进图鉴才存） |
| 设置 | `/settings` | 形象、外观、聊天模型、关怀、数据与迁移、退出 | ✅ |

- **分发边界**：`/tools/` 前缀是本地客户端功能；网页版路由守卫把它们送回对话，页头在这些页面显示云端接口声明。界面上的隐藏不是授权，服务端独立拒绝。
- **页签**：组合入口复用 `TabbedPage`，页签与 `?tab=` 同步；被组合的原页面以 `embedded` 方式嵌入，不重复页头。
- **旧链接**：旧路由（发现、个人页、记忆中心、工作台、日程/倒数日/提醒/手帐/自习、日记/读书/来信、化妆间/衣柜）一律重定向到新入口，关怀卡与外部深链不失效。
- **不做**：不新增平行入口或第二套注册表；不在对话里放常驻预设面板；不为同一个问题提供两个开关。

## 9. 本子：对话写在信纸上（2026-09-22）

产品负责人决定：对话不用气泡，整段对话是一张信纸，你写的和她回的都以手写字落在横格上；不往下无限延伸，写满一页就轻轻翻到下一页。2026-09-22 追加：这一张纸装订成**一本本子**——左边一条封皮，翻页绕左边封线从右往左翻，开头是封面，宽屏也只摊开一页。实现在 `apps/web/src/components/letter/`，令牌在 `packages/design-tokens/tokens.css`，样式在 `globals.css` 的「信纸」与「本子」两节。

- **纸与墨**：`--cs-paper`、`--cs-paper-line`、`--cs-paper-margin`；她是墨黑 `--cs-ink-her`，你是藏青 `--cs-ink-you`，辅助信息用铅笔灰 `--cs-ink-pencil`。日间与夜间各一套，两种墨色在纸上都 ≥ 9:1，铅笔灰 ≥ 5.5:1。
- **本子**：`--cs-cover`（比纸深的纸板色）、`--cs-cover-stitch`（两道细缝线）、`--cs-cover-weave`（布纹），日间与夜间各一套，封面上正文 ≥ 8.5:1、次级与辅助 ≥ 5:1。**左封皮** 14–18px 宽（手机 14px），两道缝线，安静，不做金属环；**右边纸边** 右下角两三层很浅的纸边，暗示底下还压着页；**圆角与阴影只在本子外轮廓上**，本子居中、宽度不超过 600px。
- **封面**：第 0 页，就是空白对话打开时看到的那一页——手写问候、拱窗里的她、「嗨，我是你的Amie」与开场话题，用封皮色加一层布纹，不画横格。空白对话打开就是合上的本子，只看得到封面（底下的信纸不参与点选与读屏）；点开场话题，或在本子下面的信笺上写一句放进本子，就翻开到第一页；有对话时打开仍停在最新一页，一直往前翻、翻过最早的信就回到封面。合着的时候页码那一行也是封面的纸板和布纹，整面都是封面（C20）。
- **横格**：行高就是横格间距（手机 34px、字号 17px；≥1024px 为 36px、18px），横线上移 5px 让字落在线上；每页左边一条页边线，**横格与页边线画在整张纸上，从纸顶一直贯穿到页码那一行**，所以正文和页码共用同一条页边线和同样的左右留白（窄于 480px 时页边线收到 32px）。照片、卡片、便签由分页逻辑把高度补到整数行，后面的字不压线。
- **谁写的**：墨色之外，页边写一个小小的「她」或「你」（你设了头像时是一枚小圆形头像），读屏读作「她说：」「你说：」，不只靠颜色区分。换了一天，右上角写一行日期，如「9月22日 · 夜」。段首空两格。
- **分页**：CSS 分栏（`column-width` = 页宽、`column-fill: auto`），一栏就是一页，由浏览器决定文字断在哪一行；显示哪一页靠平移。**一次只有一页**，页码从封面之后算起，封面上页码写「封面」。
- **什么时候翻**：在最后一页时，新写的字写满这一页就自动翻过去；往回翻看时她回信不把你拽走，只亮出「她回信了 · 翻到最新一页」；你写下一句会翻回最新一页；翻到最早的一页再往前，先取更早的信，没有更早的就回到封面。字体加载、重排引起的换页直接到位，不播动画。
- **怎么翻**：
  - **手机上用手指翻**（2026-09-24，C19）：按住横着拖，这一页跟着手指绕左边封线翻，纸的外边缘一直停在手指底下。往左拖翻到下一页，往右拖把上一页从左边翻回来。
  - **松手**：拖过约三分之一页宽，或者轻轻一甩，就顺势翻完；不够就落回原处，只减速、不回弹。手指停住再松开不算甩。
  - **例外**：竖着划是在滚动，不翻；一下就松手的快滑照旧翻页；鼠标拖动留给选字。
  - **其他方式**：电脑上 ← → 与 PageUp / PageDown（焦点在输入框或有弹窗时不响应）；用 Tab 移到别的页上的链接或按钮时自动翻过去。页码变化经 `aria-live` 读出。
- **翻页动效**：**绕左边封线翻**，父层给 1600px 景深。往后翻：把眼前这一页拓印一份盖在上面，`transform-origin: left center`，`rotateY(0 → -180deg)`——右边缘先翘起、再翻向左边（700ms，减速，不回弹）；翻过一半就看不见这一页的正面，露出纸的背面（一层淡阴影）。往前翻是新的一页从左边翻回来：先铺一层旧页的静影，等新的一页画出来再拓印一份从 `rotateY(-180deg)` 转到 `0deg`，落定后两层一起撤掉。拓印不可交互、对读屏隐藏，翻出纸外的部分裁在本子内。
  - **用手指翻时**（C19）：不播 700ms 的整段动画，转到哪由手指决定，写进拓印的 `--turn`（0 平摊、1 翻到左边）。纸的外边缘在「宽 × cos(π·turn)」，所以一直停在手指底下。越往上翘，靠外那一边越暗一点，像纸被捻起来。松手后用 160–520ms 落定，只减速、不回弹。
  - `prefers-reduced-motion` 下不翻，也不跟手，改为旧页淡出、新页淡入（200ms）。
- **不是字的东西**：照片像胶带贴上的小相片，正好六行高；代码和表格贴成印刷体小卡片，不拆到两页，太长在卡片里滚动；她想对你说的话、「帮我记住」卡像夹在这一页里的便签；她办的事用铅笔灰一行小字；本地安全模板像一枚小印章。
- **手帐小装饰（2026-09-23，C18）**：
  - 封面上，拱窗用一段纸胶带贴着，角落一枝压花，问候语前一个时段小画；
  - 日期前一个时段小画（晨、昼、昏、夜）；
  - 页码那一行右边一枚植物小贴纸，按页码固定；封面那一页、有危机干预的那一页不贴；
  - 她的来信压一枚火漆印，「她」页看信时信头一张邮票。
  - 全部静止，不压正文；设置 → 外观「小装饰：没有」时全部不显示。见[手帐装饰](02-设计/手帐装饰.md)。
- **落笔的地方：本子下面的一张小信笺**（2026-09-24，C20）：
  - **为什么挪出来**：以前输入框是本子最底下那一行，胶囊式的圆图标和实心发送键压在手写横格上，多行时字的行距和横格对不上；点了发送字还留在输入框里，要等她回完才清空。产品负责人定下：先写在本子外面，点发送才写进本子。
  - **样子**：和本子的纸面左右对齐（让开左边封皮），中间空 12px。同样的纸 `--cs-paper`、同样的手写字（跟着「手写 / 印刷」走）与「你」的藏青墨，16px（手机上聚焦时不被放大），不画横格——这是写给她之前的草稿。圆角 10px，一圈纸边线加纸的阴影；写字时整张信笺亮起 2px 焦点环。
  - **按钮**：语音、照片（本地客户端还有文件）是铅笔灰的细线图标，44px 触控，和页码那一行的翻页按钮一个样子。发送是一枚小墨章：有东西可放时是蘸满墨的双圈小章（像邮戳），空着或她还在写时只是一圈铅笔印。待发的照片像本子里贴的小相片（白边、歪一点）。
  - **放进本子**：点发送（或 Enter），字马上离开信笺：那几行在信笺上往上飘 10px、淡去（480ms），淡完信笺才收回一行高；本子里你那一段同时慢慢洇开（560ms，只改透明度，翻页的拓印里不播）。`prefers-reduced-motion` 下两段都不播。发送没成（失败或被作废）原样放回信笺，这期间新写的字接在放回来的那段后面。
  - **她回信时**：信笺照样能写、能说，墨章先不蘸墨；信笺上有字时，下面用铅笔灰写一行「她写完这一段，就能放进本子」（读屏经 status 读出一次）。
  - 读屏名称「聊天消息」「发送消息」与快捷键（Enter 放进本子、Shift+Enter 换行、组词时 Enter 不发送）不变。
- **页边铅笔批注：她翻过的书**（2026-09-24，C21）：
  - **什么时候有**：她这一段写的时候带上了书籍技能的章节，写完后在这一段下面用铅笔灰 `--cs-ink-pencil` 写一行「翻过的书 · 《嫉羡与感恩》第十章」，前面一枚书签细线小画（算小装饰，关掉小装饰时一起收起）。一段最多两章。
  - **只写「翻过」**：章是按她那句话挑出来放在手边的，不一定每章都用上，所以不写「引用」「出自」。
  - **点开**：一张书签小卡，写书名、作者、版本，每章「第几章 · 章名：用途」，Amie 没采纳的部分，以及一句边界（「理论参考，不是诊断或治疗」或「一般健康信息，不是诊断或医疗服务」）。
    - 小卡压在这一页上面，**不挤动分页**：下面剩的纸够（≥220px）就往下摊，不然往上；高度不超过那一侧剩下的纸，多了在卡里滚。
    - 再点一下、点别处或按 Esc 收起。
  - **尺寸与读屏**：批注那一行正好一行横格高，点按范围上下补足 44px；读屏名称「她写这段时翻过的书 · 《…》第…章」，带 `aria-expanded`。
  - **不出现**：还在写的一段、危机干预那一段、小心模式的一轮（这时本来就不翻书）、退回本地模板的一段、设置 → 外观「页边批注：没有」（存在这台设备上）。静止，不播动效。
  - **她自己放进书架的书**（2026-09-25，C22）：同一行里接着写「《书名》第 2 章」，一轮最多一段，排在 Amie 的藏书后面。小卡写书名、作者、「第几章 · 章名」，以及一句「这是你放进书架的书，Amie 没有审校它的内容」；没有用途和「没采纳」。书在这台设备上时，章名后面有一个「翻到这一段」（铅笔批注里唯一的链接，用她回信的墨色 `--cs-ink-her` 加下划线，点按范围上下补足 44px），打开阅读器落在那一段，顶上提示「这是她回你时翻到的那一段，读到哪儿不会被改掉」，看一眼不改阅读进度。
  - **提不提书名是另一回事**：设置 → 外观「回答里提到书：提一句 / 不提」（默认不提，跟着账户走）只管她回答的正文里要不要说「《……》里讲过」；批注照旧由「页边批注」那个开关管。
- **印刷体退路**：设置 → 外观「信纸上的字：手写 / 印刷」，存在这台设备上；只换字，本子、横格、翻页都不变。
- **存档页**：以前的对话也写在信纸上，不分页，竖着滚。
- **不变的边界**：AI 身份常驻条、危机弹窗、首次使用的 AI 声明与两小时提醒不改。手记、读书、「她」页、设置页不改成信纸。
