# Amie UI 设计系统规范 V3.0

> 状态：本地优先基础版实施基线  
> 更新日期：2026-09-16（§5、§6 随功能收拢更新，新增 §8 信息架构）；2026-09-15（§2 色板对齐 09-09 鼠尾草换肤；§3 动效条款与 §7 静谧层随界面质感升级更新）

## 1. 设计立场

产品首先传达“私密、轻松、像闺蜜一样自然”，不以模型参数、推理能力或技术感作为主视觉卖点。界面必须持续说明 AI 身份与回复来源，但不把用户置于配置术语和供应商术语中。

四项原则：

- **隐私可见**：本地处理、云端备用、图片不上传等状态使用稳定文字和来源标签，不只依赖颜色。
- **柔和但清晰**：低饱和色只承担背景与分区；正文、按钮、焦点和危机状态使用独立高对比语义色。
- **像朋友而非客服**：中文短句、圆润层级、克制动效；不使用虚假的在线状态、真人暗示或情绪绑架。
- **能力不冒充上线**：虚拟试衣间、虚拟化妆间等未实现模块只能展示“规划中”，不得提供伪上传、伪生成或伪支付。

## 2. 品牌粉彩

2026-09-09 起为鼠尾草绿植物系（对齐落地页 Botanical Editorial），日间值如下；夜间值与唯一来源见 `packages/design-tokens/tokens.css`：

| Token | 色值 | 主要用途 |
| --- | --- | --- |
| `--cs-pastel-blush` | `#F0F4E8` | 对话暖区、轻提示、柔和选中面（柔雾绿） |
| `--cs-pastel-mist` | `#E2EDE4` | 信息、说明、冷静分区（青绿雾） |
| `--cs-pastel-sprout` | `#F4F9E8` | 本地就绪、隐私与成功表面（嫩芽） |
| `--cs-pastel-apricot` | `#F6F0E2` | 妆教、温暖提示与发现页点缀（米杏） |
| `--cs-pastel-lavender` | `#E7EFE2` | 展示型表面（苔绿） |

禁止直接把粉彩用于小字号正文或唯一状态信号。主操作使用鼠尾草绿 `#5F7049`，信息/焦点使用深松绿 `#35594A`，本地成功使用深绿 `#53633B`，危险使用 `#B42318`。

## 3. 形态、排版与动效

- 正文字体只使用系统中文字体栈，不请求 Google Fonts 或其他运行时字体服务。展示标题与手写点缀同样只用系统字体栈（见 §7）。
- 正文默认不小于 14px；辅助说明不小于 11px，并保证语义色对比。
- 控件最小触控尺寸 44×44px；表单必须有可见标签，图标不能替代名称。
- 卡片圆角以 30px 为基线，控件约 18px，底部面板 34px（`--cs-radius-card/control/sheet`）；聊天气泡 24px、输入胶囊 26px。阴影低透明、分层柔和，不做高亮霓虹。
- 动效只减速、不回弹：交互反馈 200–320ms；入场 420–640ms；环境循环 ≥8s，且只动 transform/opacity。必须响应 `prefers-reduced-motion`（环境动效静止、入场延迟归零），核心流程不依赖动画完成。
- 手机全屏优先；桌面可使用居中的手机内容框，但不得限制浏览器缩放。

## 4. 插画与角色资产

插画采用低饱和粉彩、留白、柔和轮廓和明确友善表情。人物呈现避免单一审美模板、幼态化、性暗示、肤色刻板印象和“完美变美”暗示。AI 形象必须保留非真人线索。

资产进入主流程前必须完成：来源/授权记录、人工审看、移动端裁切、替代文本、体积优化。纯装饰图使用空 `alt`；承载状态的图必须由邻近文字完整表达含义。不得为填充页面临时下载运行时图片。

当前基础版复用仓库内已跟踪的 Logo、AI 头像与聊天空状态插画。后续虚拟试衣和虚拟化妆资产仍复用本规范，不自动获得上传用户照片的权限。

## 5. 核心页面合同

- **登录**：只显示手机号、固定内测码、登录状态与隐私范围；没有“获取验证码”伪交互。
- **对话**：只有一种对话。AI 身份常驻；消息标明来源（云端模型 / 安全模板）；模型失败保留输入。页头只放她的名字、AI 标识与设置，不放人格徽章或模式切换；空白对话只有问候与最多 4 个开场。
- **她**：说话方式三选一，切换明确“下一条生效”；记忆由用户显式创建、编辑、删除与清空，待确认的理解由用户决定是否算数。
- **安排**：一处列出所有定时安排，按今天 / 接下来 / 重复 / 已暂停 / 已完成分组；交给她做的事如实标注执行未接通。
- **设置**：形象、外观、唯一的聊天模型授权开关、关怀、数据与迁移；从未真正投递的开关不得出现。
- 已下线：本地模型管理（2026-09-07）、妆教（2026-09-05）、发现页（2026-09-15 并入导航）。

## 6. 扩展与验收

新入口只在 `apps/web/src/features/registry.js` 登记（§8），拥有真实路由、隐私合同、服务端白名单输入与 E2E 后才能加入；优先并入已有入口的页签，而不是新开一个入口。独立模块复用共享令牌、主应用 access token 和主 API 模型路由。

每次发布至少检查键盘顺序、焦点可见、对话框焦点管理、live region、44px 触控、200% 缩放、reduced-motion，以及 axe critical/serious。通过这些门禁不等同于正式 WCAG 认证。

## 7. 静谧层（2026-09-15）

目标是让用户打开 Amie 时心能静下来：少即是静、慢即是柔、柔软要有质感。令牌在 `packages/design-tokens/tokens.css`，样式在 `apps/web/src/styles/globals.css`。

- **动效令牌**：`--cs-ease-calm`（长尾减速）、`--cs-ease-breathe`（正弦往复）；`--cs-dur-quick/soft/settle` 为 200/320/560ms，`--cs-dur-breath` 为 8s（4 秒吸、4 秒呼）。入场动画一律 `fill-mode: backwards`，结束后不残留 transform/filter。
- **环境光（晨雾 / 月下森林）**：`AmbientMist` 在应用主区和登录页铺三团 `--cs-glow-1/2/3` 径向光，48–64s 往复漂移（手机两团），只动 transform，空闲时不触发布局。叠加 `--cs-grain-opacity` 的纸张颗粒（SVG 噪声平铺）。设置自定义主页背景时不渲染。
- **材质**：`.glass-bar`、`.glass-strong`、`.glass-mist` 为半透明底加背景模糊，不支持时退回实色。阴影统一为分层柔影（`--cs-shadow-soft/float` 等）；聊天气泡用实色 `--cs-bubble-ai/user`，不用渐变、不描外框。
- **字体栈**：`--cs-font-display`（Palatino / Georgia / 思源宋体等，刻意不含 SimSun）用于品牌字标与展示标题；`--cs-font-hand`（楷体系）只用于一两句手写点缀，如时段问候、登录标语。
- **品牌标识**：`BrandMark` 由落地页同款单叶线稿加斜体衬线 "Amie" 组成，用于侧栏与登录页。
- **聊天页**：消息区上下边缘渐隐；只有流式中的新消息入场（AI 消息模糊沉降、用户消息升起），流式末尾有呼吸墨点；枝叶装饰只在空白会话出现；输入区为悬浮胶囊，正文框聚焦时整圈显示焦点环。
- **不变的边界**：AI 身份常驻条、来源标签、危机弹窗文案与对比度要求（≥4.5:1）不因质感调整而弱化；危机弹窗入场缩短到 240ms。

## 8. 信息架构（2026-09-16）

一件事只有一个入口，同一批功能只有一种组织方式。导航由 `features/registry.js` 这一份注册表驱动，`AppNav` 放在会话列表底部，侧栏与手机抽屉共用。

| 入口 | 路由 | 内容 | 网页版 |
| --- | --- | --- | --- |
| 对话 | `/chat` | 唯一的会话类型；本地客户端可附文件、交给她后台执行 | ✅ |
| 她 | `/her` | 说话方式、她的节奏、她记得的你（已记住 / 待确认 / 关系） | ✅ |
| 安排 | `/tools/schedule` | 定时安排：一次、每天、每周、每月、每年 | 本地 |
| 手记 | `/tools/notes` | 日记 / 读书 / 来信三个页签 | 本地 |
| 经期 | `/tools/period` | 经期记录与预测 | 本地 |
| 装扮 | `/tools/style` | 化妆 / 衣柜两个页签 | 本地 |
| 设置 | `/settings` | 形象、外观、聊天模型、关怀、数据与迁移、退出 | ✅ |

- **分发边界**：`/tools/` 前缀是本地客户端功能；网页版路由守卫把它们送回对话，页头在这些页面显示云端接口声明。界面上的隐藏不是授权，服务端独立拒绝。
- **页签**：组合入口复用 `TabbedPage`，页签与 `?tab=` 同步；被组合的原页面以 `embedded` 方式嵌入，不重复页头。
- **旧链接**：旧路由（发现、个人页、记忆中心、工作台、日程/倒数日/提醒/手帐/自习、日记/读书/来信、化妆间/衣柜）一律重定向到新入口，关怀卡与外部深链不失效。
- **不做**：不新增平行入口或第二套注册表；不在对话里放常驻预设面板；不为同一个问题提供两个开关。
