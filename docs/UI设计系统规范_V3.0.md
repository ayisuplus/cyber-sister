# 赛博姐妹 UI 设计系统规范 V3.0

> 状态：本地优先基础版实施基线  
> 更新日期：2026-08-30

## 1. 设计立场

产品首先传达“私密、轻松、像闺蜜一样自然”，不以模型参数、推理能力或技术感作为主视觉卖点。界面必须持续说明 AI 身份与回复来源，但不把用户置于配置术语和供应商术语中。

四项原则：

- **隐私可见**：本地处理、云端备用、图片不上传等状态使用稳定文字和来源标签，不只依赖颜色。
- **柔和但清晰**：低饱和色只承担背景与分区；正文、按钮、焦点和危机状态使用独立高对比语义色。
- **像朋友而非客服**：中文短句、圆润层级、克制动效；不使用虚假的在线状态、真人暗示或情绪绑架。
- **能力不冒充上线**：虚拟试衣间、虚拟化妆间等未实现模块只能展示“规划中”，不得提供伪上传、伪生成或伪支付。

## 2. 品牌四色

用户提供的四色是唯一基础粉彩，代码值由 `packages/design-tokens/tokens.css` 管理：

| Token | 色值 | 主要用途 |
| --- | --- | --- |
| `--cs-pastel-blush` | `#FDF1F0` | 对话暖区、轻提示、柔和选中面 |
| `--cs-pastel-mist` | `#DEF0F5` | 信息、本地模型说明、冷静分区 |
| `--cs-pastel-sprout` | `#F4F9E8` | 本地就绪、隐私与成功表面 |
| `--cs-pastel-apricot` | `#FAF0EA` | 妆教、温暖提示与发现页点缀 |

禁止直接把粉彩用于小字号正文或唯一状态信号。主操作使用深莓红 `#8A3F56`，信息/焦点使用深青 `#315E6B`，本地成功使用深绿 `#53633B`，危险使用 `#B42318`。

## 3. 形态、排版与动效

- 正文字体只使用系统中文字体栈，不请求 Google Fonts 或其他运行时字体服务。
- 正文默认不小于 14px；辅助说明不小于 11px，并保证语义色对比。
- 控件最小触控尺寸 44×44px；表单必须有可见标签，图标不能替代名称。
- 卡片圆角以 24px 为基线，控件约 14px；阴影低透明、短距离，不做高亮霓虹。
- 常规动效 160–200ms；必须响应 `prefers-reduced-motion`，核心流程不依赖动画完成。
- 手机全屏优先；桌面可使用居中的手机内容框，但不得限制浏览器缩放。

## 4. 插画与角色资产

插画采用低饱和粉彩、留白、柔和轮廓和明确友善表情。人物呈现避免单一审美模板、幼态化、性暗示、肤色刻板印象和“完美变美”暗示。AI 形象必须保留非真人线索。

资产进入主流程前必须完成：来源/授权记录、人工审看、移动端裁切、替代文本、体积优化。纯装饰图使用空 `alt`；承载状态的图必须由邻近文字完整表达含义。不得为填充页面临时下载运行时图片。

当前基础版复用仓库内已跟踪的 Logo、AI 头像与聊天空状态插画。后续虚拟试衣和虚拟化妆资产仍复用本规范，不自动获得上传用户照片的权限。

## 5. 核心页面合同

- **登录**：只显示手机号、固定内测码、登录状态与隐私范围；没有“获取验证码”伪交互。
- **聊天**：AI 身份常驻；消息标明“本地模型 / 云端备用 / 安全模板”；模型失败保留输入。
- **人格与记忆**：人格切换明确“下一条生效”；记忆由用户显式创建、编辑、删除与清空。
- **本地模型**：实例管理员可发现、测试并保存 llama.cpp；普通用户只见去敏状态；页面不接收模型密钥。
- **发现**：妆教可进入；规划中的试衣和妆效能力不可点击。
- **妆教**：原始图片和视频帧只在浏览器处理；模型解释只发送规范化标签和内置 `lookId`。

## 6. 扩展与验收

新能力先在 `apps/web/src/features/capabilities.js` 注册为 `planned`，拥有真实路由、隐私合同、服务端白名单输入与 E2E 后才能改为 `available`。独立模块复用共享令牌、主应用 access token 和主 API 模型路由。

每次发布至少检查键盘顺序、焦点可见、对话框焦点管理、live region、44px 触控、200% 缩放、reduced-motion，以及 axe critical/serious。通过这些门禁不等同于正式 WCAG 认证。
