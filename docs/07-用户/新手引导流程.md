# 赛博姐妹 · 新手引导流程

> **文档版本**：V1.0
> **创建日期**：2026-08-31
> **定位**：首次使用的完整引导设计规格
> **读者**：产品设计、前端开发、QA
>
> 本文定义"一个新用户从打开到聊上第一句"应该经历什么。不含技术实现，只描述体验与规则。

---

## 一、引导目标

新手引导要同时完成四件事，缺一不可：

| 目标 | 为什么 | 验收标准 |
|------|--------|----------|
| **说清她是 AI** | 合规硬要求，避免误导为真人 | 首次打开有全屏身份提示，且每屏常驻标识 |
| **降低开口门槛** | 第一次跟 AI 说话是尴尬的 | 有话题引导，不是空白输入框对着用户 |
| **建立"她记得住"的认知** | 这是核心差异化，不说用户不知道 | 引导中至少一次点明记忆能力 |
| **讲清边界** | 不做咨询、不做恋人、不替你决定 | 明确告知，但不吓唬人 |

---

## 二、完整流程

```
打开应用
   ↓
① AI 身份全屏提示（必看，不可跳过）
   ↓
② 登录（白名单手机号 + 固定验证码）
   ↓
③ 首次欢迎语（她主动开口，不等用户）
   ↓
④ 人格初选（三选一，可跳过用默认）
   ↓
⑤ 首句引导（给她一点关于你的信息 → 顺带教会"记忆"）
   ↓
⑥ 进入正常聊天
   ↓
⑦ 适时提示：工具箱 / 妆教（不打断，不弹窗轰炸）
```

---

## 三、各环节设计

### ① AI 身份全屏提示

**触发**：每次全新会话首次打开（未登录状态下也要能看到，或登录后立即展示）。

**必须包含**：

- 明确的话："我是 AI，不是真人"
- 她能做什么（陪你聊、记得你说的事、24 小时在线）
- 她不能做什么（不做心理咨询、不是恋人、不替你做重大决定）
- 一个"我知道了"按钮

**规则**：

- **不可跳过**，必须点确认
- 文案温暖但有分寸，不卖惨、不卖萌、不制造情感依赖
- 不写"我会永远陪着你"这类绝对化承诺

**文案示例**（待产品负责人核定）：

> 嘿，先说清楚几件事。
>
> 我是 AI，不是真人。我能陪你聊、记得你说过的事、24 小时在线。
>
> 但我不做心理咨询，不是你的恋人，也不会替你做重大决定——要不要分手、要不要辞职，我会帮你理清，但决定权在你。
>
> 你难过的时候我在，你犯蠢的时候我也直说。就这样。

### ② 登录

**内测规则**：

- 白名单手机号 + 固定验证码
- 非白名单号码和错误验证码返回**统一提示**，不区分（避免暴露号码是否在名单里）
- 不提供"获取验证码"按钮（内测无真实短信），登录必须等真实 API 结果

**文案要求**：

- 号码不对："这个手机号还没有内测资格，找邀请你的朋友确认一下吧"
- 不写"用户不存在"这类可能被探测的话术

### ③ 首次欢迎语（她主动开口）

**规则**：登录进聊天页，**她先说话**，不等用户输入。空白聊天界面是最劝退的。

**欢迎语要做的**：

1. 打个招呼，有人味
2. 抛出 2-3 个话题入口（降低开口成本）
3. 点一句"记住你说的事"（埋下记忆认知）

**文案示例**（待核定）：

> 终于等到你了。
>
> 随便聊点什么吧——今天过得怎么样？还是有件事憋着不知道跟谁说？
>
> 对了，你告诉我的事我会记住，下次不用重复说。想让我记住什么，随时告诉我。

**禁止**：

- 不写"我是你的专属 AI 女友/伴侣"
- 不承诺"永远""绝对""24 小时秒回"
- 不问"请问有什么可以帮您"（客服腔）

### ④ 人格初选

**时机**：欢迎语之后，首次聊天之前（或第一次对话之后，二选一，需 A/B 决定）。

**呈现**：三张卡片，各配一句"什么样"的描述 + 一个示例回答。

| 人格 | 描述 | 示例回答风格 |
|------|------|--------------|
| 温柔姐姐 | 先共情，后分析。难过时的首选 | "抱抱，这事儿确实委屈你了……" |
| 毒舌互怼 | 说话带刺，但刺得有道理 | "你清醒一点，他哪点值得你这样" |
| 疯批搭子 | 冷静拆解，不讲情面 | "我们先把事实和情绪分开看" |

**规则**：

- **可跳过**，跳过则用默认人格
- 强调"随时能改"，不制造选择焦虑
- 切换后已记住的事和聊天记录不变

> ⚠️ **当前代码默认人格为 `toxic`（毒舌互怼）**，见 `apps/api/src/routes/auth.js` 新用户创建逻辑。
> 这是实现现状，**不一定是产品意图**——首次登录就遇到毒舌，对部分用户可能劝退。
> 已列入下方待定事项第 2 条，需产品负责人裁定。

### ⑤ 首句引导（教会"记忆"）

**目的**：让用户体验到"她记得住"，这是核心卖点。

**做法**：在她回复中，当识别到用户透露了个人信息（职业、城市、宠物、重要事件）时，**自然地**确认并提议记住。

**示例**：

> 用户："我养了只橘猫，最近老是吐"
> 她："胖虎又吐了？（先关心）……我记一下'养了只橘猫叫胖虎，最近呕吐'？下次直接跟我说。"

**规则**：

- **必须征得同意**，不能偷偷记
- 提议要自然，不要每次都弹一个正式的确认框（打断感强）
- 用户拒绝则不再提

### ⑥ 正常聊天

进入常规对话。常驻要素：

- 顶部/底部 AI 身份标识
- 打字指示器
- 输入框 + 快捷工具入口

### ⑦ 功能提示（克制）

**原则**：不弹窗轰炸，不打断对话。

**推荐做法**：

- 用户聊到相关场景时**顺势**提示（说到"明天生日"→ 轻提示"要不要加个倒数日？"）
- 或放在工具箱入口做一个安静的角标
- **不做**首屏弹窗引导教程、不做多页滑动引导图

**要告知但不强推**：

- 工具箱（待办 / 倒数日 / 经期 / 提醒）
- 妆教模块（`/makeup/`）
- 记忆管理

## 四、文案红线

所有引导文案必须遵守：

| 红线 | 说明 |
|------|------|
| 不冒充真人 | 任何文案都不得暗示她是真人 |
| 不做医疗/心理诊断 | 不出现"治疗""诊断""症状""病情" |
| 不承诺效果 | 不出现"让你变美""保证有效""包你开心" |
| 不情感操控 | 不用"你不充钱她就会消失""只有我对你好" |
| 不绝对化 | 不用"永远""绝对""24 小时秒回"（除非真能做到且已验证） |
| 不制造依赖 | 鼓励真实人际关系，不鼓励替代 |
| 危机资源需核验 | 任何热线/求助信息必须产品负责人书面批准并记录来源与核验日期（Spec §5 **硬性要求**） |

---

## 五、无障碍要求

引导流程必须满足（对齐 Spec §9 发布门）：

- 键盘全程可达，焦点顺序合理
- 焦点陷阱：弹窗内焦点不逃逸（已有 `useDialogFocusTrap`）
- 触控目标 ≥44px
- 支持 `prefers-reduced-motion`（动画降级）
- live region 播报状态变化（如"正在输入"）
- axe 检查无严重问题
- 文案对比度达标

## 七、验证方式

引导流程完成后，用新账号走一遍，逐项打勾：

- [ ] 首次打开看到 AI 身份提示，且不可跳过
- [ ] 提示文案包含"能做什么"和"不能做什么"
- [ ] 登录后她主动开口，不是空白界面
- [ ] 有话题入口，不冷场
- [ ] 人格可三选一，可跳过
- [ ] 切换人格后记忆与历史不变
- [ ] 透露个人信息时她会自然提议记住，且征得同意
- [ ] 全程 AI 标识可见
- [ ] 无弹窗轰炸，功能提示克制
- [ ] 键盘可达、44px、reduced-motion、live region 均正常
- [ ] 所有文案过一遍红线检查表
