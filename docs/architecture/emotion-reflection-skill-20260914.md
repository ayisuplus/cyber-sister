# 《嫉羡与感恩》内置技能与预设

状态：✅ 当前有效 · 2026-09-14

## 取舍

用户授权沿用书籍转技能流程，应用于 Amie。来源为克莱因文集中文本（九州出版社，2017），并非一本现代心理自助手册。提取约 30 万字符、估算 188K token，目录包含 16 篇主要论文。采用目录扫描与重点选读，不制作全书复刻或全部章节摘要。

选择第 1、2、10、14、16 章相关内容，形成五个产品主题：比较与嫉羡、矛盾与整合、内疚与修复、善意与感激、孤独与理解。保留作者理论术语以便查阅，日常陪伴使用具体事件与感受的语言。对话步骤和实例明确标为 Amie 改编。

不执行心理诊断、移情或儿童游戏分析，不倒推用户婴儿经历、不诱导创伤记忆、不将母亲或用户归责为一切困扰的来源。感恩不是原谅伤害的义务，整合不是强制折中；不以 AI 承诺填补孤独。理论资料不是临床证据。

## 实现

- `apps/api/src/skills/emotion-reflection/` 包含 SKILL、五主题、词表、模式、速查与来源；全文没有进入仓库或前端。
- `emotionReflectionSkill.js` 以静态白名单加载核心和最多两个主题；用户明确询问理论时才追加术语表。只读本地维护文件，不把用户文字拼为系统指令。
- `llmService.js` 普通、流式聊天均接入；其他 scene、工作台模拟和云端同意机制不变。不新增数据库写入或分析档案。
- 当前用户明确主题或明确短追问可触发；不读助手猜测或更早用户话题。明确拒绝分析时退出，最近用户已拒绝的追问不重新激活。规则为保守词项匹配，非完整自然语言意图识别；泛泛的“心情不好”不触发此理论技能。
- `ChatSkillPresets.jsx` 替代原身体预设专用组件，统一“聊天预设 · 身体与情绪”入口，两组分别为身体呵护（6 项）、情绪与关系（5 项）。选择只填草稿，不发送；切换主题保留已有文字，文字/图片存在或发送中不可覆盖；工作模式不显示。
