# 工作模式主题与动态素材

> ✅ 当前有效 · 2026-09-12 · 工作区实现，待用户验收

## 信息组织

工作模式原先同时展示全部 10 项功能。现在先选择一个与当前意图相符的主题，再显示该主题的 2–3 项行动。默认进入“安排今天”，不新增工具、路由或后台数据结构。

| 主题 | 保留的功能 |
| --- | --- |
| 安排今天 | 日程与提醒、专注自习、手帐打卡 |
| 记录生活 | 日记、一起读书、大姨妈记录 |
| 灵感装扮 | 化妆间、3D 衣柜 |
| 关于我们 | 她的工作台、她的信 |

`features/workspaces.js` 只保存主题及条目 ID，由原有 `capabilities.js` 和 `toolbox.js` 解析名称、路径、状态及隐私说明。横竖屏复用 `WorkHubNavigation`，共享选择和暂停状态。分类是普通按钮组，支持 Tab、Enter、Space 和可见焦点，不引入不完整的 tabs 键盘协议。

## 视觉与动效

新增四张原创、可编辑的 SVG 纸贴：计划本与绿植、书页与热茶、镜子与蝴蝶结、信封与枝叶。它们作为装饰使用空替代文本；资源失败时显示对应图标，功能名称始终保留。没有图标覆盖透明插画的问题。

选中纸贴轻微浮动，叶片标记缓慢摆动，切换后的操作清单短暂出现。动效不承担功能或状态信息。工作模式由自己的动效开关管理装饰，聊天页的漂浮涂鸦仅在聊天模式展示。

`AmbientMedia` 在进入视口且页面可见时播放；离屏、切到后台、被横屏书桌覆盖或卸载时停止。系统减少动效或浏览器省流量模式直接使用静态图，播放/加载失败同样回退。用户暂停后切换主题，操作清单仍完整可见。

横屏背景独立裁切，避免放大视频撑出横向滚动条。沉浸层保留 AI 身份提示；Escape 关闭、Tab 约束焦点并在关闭后恢复。其他正式弹层出现时让位，本轮横屏不再自动抢回。全局快捷键不穿透弹层，旧弹层卸载也不会从新弹层抢走焦点。

## 本地生成记录

ComfyUI 用于开发期间制作静态资源，应用运行时不连接 ComfyUI。使用用户现有 MiniMax H3 工作流的独立副本，原工作流保持不变。当前服务实测为本机 `127.0.0.1:8188`，使用已安装的模型和节点，没有模型下载或付费 API 调用。

完整工作流副本、输入、提示词及原始候选保存于项目外层的 `asset-work/workdesk-20260912/`。项目原有 `banner-workspace.png` 是参考图。测试了 ref2va 与同图首尾约束 fl2va 两个候选：前者开头有画风变化，后者有明显明暗变化，均未原样接入。最终采用前者稳定的后半段，以 1 秒重叠淡化处理接缝，移除音轨和生成元数据，压缩为 960×544、24 fps、2.875 秒的 H.264 循环（约 168 kB）；静态封面与循环首帧一致（约 35 kB）。原始候选和处理记录均保留。生成完成、逐帧检查、页面检查和用户审美验收分别记录，不以任务完成代替视觉验收。

## 验证

- 前端 80 个测试文件、647 个测试通过；typecheck 通过。
- 实际 Chromium 12 个相关浏览器用例通过，覆盖桌面和手机、四组十入口、暂停后切换、320px、横屏选择与焦点恢复。
- 四个主题及横屏的 axe 严重/致命问题为 0。此结果不等同于完整无障碍认证。
- 原有本地 `@axe-core/playwright` 的构建入口缺失；此次浏览器检查使用已安装的同版 `axe-core` 临时注入执行同一批用例，未下载依赖。正式测试保留正常依赖引用。
- 原有 Vite 优化缓存出现 504，检查使用临时缓存目录；构建输出也使用临时目录，未覆盖旧 `dist`。
- 本次相关 ESLint 无错误；全局快捷键处理器和聊天页各有一条复杂度警告。3D 衣柜原有大块构建提示仍存在。

最终视频规格、哈希和采用结果见资源目录的 `work-assets.json`。浏览器初轮截图使用原氛围视频；替换后的媒体另做页面播放与循环检查。
