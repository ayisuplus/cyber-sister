# 工作任务的外部提交确认

状态：✅ 当前有效。更新于 2026-09-15。第六批本地实现与验收，尚未发布或部署 VPS。

## 用户可见行为

工作后台任务可以准备网页提交。模型使用 `browser_act` 的 `submit=true` 和操作说明后，浏览器截住实际请求，任务卡片展示目标网址、方法和完整发送内容。用户选择「确认提交一次」才放行该请求；「不提交」会阻止本任务继续申请外部写入。确认有五分钟有效期，不因用户没有回应而自动通过。

JSON 保留原文，避免解析和重新序列化改变大整数或合并重复字段；URL 编码表单显示解码字段，同时可以展开查看请求原文。

卡片区分等待确认、已确认、正在提交、已收到网站响应、拒绝、过期、取消和结果不确定。收到 HTTP 响应不等于网站业务已经成功；模型仍要核对页面与结果。任务可保留截图和来源，成功回合继续与消息、会话文件、一次角色成长同事务提交，不自动建立正式记忆。

此能力目前用于匿名页面的表单与同源文本请求，支持 GET 导航、POST、PUT、PATCH、DELETE，正文最多 8 KB，类型为 UTF-8 文本、JSON 或 URL 编码表单；每个任务最多五次确认。普通浏览仍沿用公开 GET 通道。登录、Cookie/Authorization 转发、文件上传、跨域预检、付费媒体和账号连接器仍待实现；不能把当前 GET 约束理解为所有业务读取都没有副作用。

## 执行与恢复

`WorkAction` 独立保存不可由确认接口修改的请求详情、摘要、步骤和执行租约。确认接口只接受 approve/reject，不接受新的目的地或正文；跨用户或跨任务返回 404，重复或过期确认返回 409。用户锁与任务锁顺序保持一致，发送前原子消费批准状态，再次检查租约、期限和请求摘要。

浏览器工作进程不能自行批准请求。API 只处理当前尚未结束的提交命令，网页不能添加授权请求头；工作进程在待确认请求完成前提前报告操作完成，会被关闭。请求沿用公开地址、全部 DNS 结果、固定 IP、网络取消与响应大小限制；只在这些校验和最新云端授权通过后消费确认并发起连接。

每个确认只授权一次网络请求，不自动重试，也不自动跟随写入重定向；后续需要提交的请求重新等待确认。允许确认的浏览器最长十分钟，容器十一分钟到期回收；页面提交命令最多 330 秒，以容纳用户核对。未开放确认的普通浏览器保持原三分钟寿命。

外部网站与本地消息不能组成同一数据库事务。若发送后连接中断、结果无法确认，或者响应已收到但工具检查点尚未保存时进程崩溃，任务进入「需要核对」，不会自动重发。只有已经保存完整工具结果的检查点可以继续后续步骤。取消不会撤销网站可能已经产生的结果，已发送或不确定的操作记录仍保留供核对；未发送的批准失效。

确认记录归属原任务，随会话/账户删除级联清理，并包含在用户数据导出中。接口和导出不暴露租约令牌或内部请求摘要，导入不会启动任务。字段更新同步推进任务更新时间，避免迟到轮询覆盖确认后的状态。

## 配置与接口

应用迁移 `20260915150000_work_actions`，重建 `apps/api/work-browser-runtime` 镜像，并在后台任务与浏览器开关之外设置 `WORK_BROWSER_WRITES_ENABLED=true`。仓库 `.env.example` 默认关闭；没有后台任务的服务端确认函数时，设置浏览器参数也不能开放提交。

`POST /api/work/tasks/:id/actions/:actionId` 的正文为 `{"decision":"approve"}` 或 `{"decision":"reject"}`，返回更新后的任务。任务列表与详情中的 `actions` 提供完整待确认数据与结果状态，使用原会话鉴权。浏览器工具无决定批准的接口。

本地启动配置已经启用。独立调试数据库 `cyber_sister_local_debug` 已在备份后应用新增表；备份经 `pg_restore --list` 校验，迁移前后 29 张已有业务表的行数与内容摘要完全一致。备份文件仅保存在仓库外的 `.local-data/backups/`，详情见本批 `local-migration.json`。此操作未涉及个人主数据库、VPS 或网络代理。
