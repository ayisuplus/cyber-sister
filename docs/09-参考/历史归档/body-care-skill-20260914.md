# 身体呵护内置技能与预设

状态：✅ 当前有效 · 2026-09-14

## 产品取舍

用户提供六层楼《女生呵护指南》(2019) 并授权自行选择适合 Amie 的内容。采用专项知识与沟通技能，而非新增人格：六种现有人格不变，健康话题中明确收起身体玩笑。六章分别形成分泌物、经期、炎症、报告、防护、自主权的选择性参考，不声称完整章节摘要或临床指南。

来源原文约 23 万字符、提取工具估算约 14 万 token（中文词数统计不适用）；采用目录与定向小节阅读，不生成全书复刻。来源位置及原始全文不进入应用。书中未经复核的治疗阈值、药物剂量、诊疗日期、恐吓式流产描述、对疼痛的归责及性别刻板语言均未采纳。

## 已实现

- `apps/api/src/skills/body-care/`：核心 SKILL、六份主题参考、就诊沟通模式、词表、取舍速查及来源记录。
- `bodyCareSkill.js`：静态白名单加载。匹配当前用户健康主题；仅明确短追问继承最近一条用户消息，不从助手推测、记忆或更早话题激活。运行时追加核心规则和最多两个主题，就诊问题附沟通模式。用户内容不拼入 system 消息。
- `llmService.js`：普通与流式聊天通过同一构造器追加技能；原人格、危机控制、输出过滤、取消与云端同意链路继续生效。其他 scene 不加载；工作台模拟服务没有改动。
- `InputBar.jsx`：聊天输入框上方折叠“聊天预设 · 身体与情绪”，身体呵护组的六个入口填入可编辑文字，不发送。已有非空文字、图片或正在发送时不可覆盖；工作模式不显示。统一组件为 `ChatSkillPresets.jsx`，同日增加情绪与关系组。
- 无新增数据库、账户健康画像、保存操作、后台任务或在线检索。对话仍按原聊天机制保存，正式记忆仍需用户确认。

## 信息来源与能力边界

来源与复核链接见 [技能来源](../../../apps/api/src/skills/body-care/sources.md)。NHS 和 WHO 仅用于维护时核对少量一般信息，不意味着在线咨询或医学认证。具体筛查、疫苗、药物选择及服务可用性应按所在地当前指南和专业评估。

路由是有意保守的词项匹配，不能识别所有隐晦表达，用户可使用预设或明确说“身体呵护”。规则属于提示词约束，不能保证模型每次遵循或构成医学分诊验收。此次使用模型替身验证请求边界，没有消费真实云端模型。

## 验证

本轮全量 API 单元测试 881 通过、23 项 PostgreSQL 集成测试因未配置隔离测试连接而跳过；Web 701 通过。类型检查、lint（零错误，含 InputBar 复杂度及其他警告）和前端生产构建通过。

- API 单元测试覆盖六主题、非健康文本、近期用户追问、助手猜测、主题切换、注入文本、最多两个主题、普通/流式一致与授权拒绝。
- 前端验证预设不自动发送、不覆盖草稿、发送失败保留输入、工作模式不出现。
- 生成技能安全扫描通过；扫描器未覆盖 `sources.md`，该文件另外人工检查，内容仅为来源说明与官方链接。
- 内置浏览器连接返回 `nodeRepl.fetch request failed`，本轮无法进行真实页面点击和移动端视觉验收；不将单元测试报告成浏览器验收。

本次只完成仓库内集成，没有发布或生产部署。书本改编产物未对外分享，个人数据库未改动。
