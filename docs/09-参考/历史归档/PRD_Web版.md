## 1. 产品定义

**一句话**：面向中国年轻女性的AI闺蜜Web应用，提供情感陪伴、工具服务和会员增值。

**目标用户**：22-28岁一二线城市女性

**核心问题**：年轻女性需要一个"懂自己"的AI闺蜜，而非客服式AI助手

---

## 2. MVP范围（P0 — 上线必备）

### 2.1 功能清单

| 优先级 | 功能模块 | 验收标准 |
|--------|---------|---------|
| P0 | **用户注册/登录** | 手机号+验证码登录，JWT鉴权 |
| P0 | **聊天界面** | AI身份标识常驻、消息气泡、输入框、发送、打字动画 |
| P0 | **人格切换** | 3种预设人格（毒舌互怼/温柔姐姐/疯批搭子），切换后聊天风格变化 |
| P0 | **Mock对话引擎** | 预设回复+规则匹配，预留真实LLM API接口 |
| P0 | **四层记忆系统** | 瞬时记忆(会话上下文)、情景记忆(30天)、语义记忆(永久)、程序记忆(标签) |
| P0 | **工具功能** | 天气提醒、待办/记事、倒数日、大姨妈记录、喝水/睡觉提醒 |
| P0 | **合规安全** | AI身份标识、2小时使用提醒、危机干预弹窗、未成年人保护 |
| P0 | **会员系统** | 免费版/会员版，权益区分，支付模拟 |
| P0 | **我的页面** | 用户信息、人格切换、记忆管理、设置菜单 |

### 2.2 明确不做（Won't Have）

| 功能 | 原因 |
|------|------|
| LLM训练/微调 | 用户要求排除，后续单独处理 |
| 语音/视频通话 | V1.5 |
| 图片生成/发送 | V1.5 |
| UGC角色创建 | V1.0不做 |
| 群聊/多人对话 | V1.0不做 |
| 虚拟形象/捏脸 | 永远不做 |
| 朋友圈/动态 | 永远不做 |
| 心理咨询功能 | 明确不是心理咨询 |

## 3. 页面清单

| 页面 | 路由 | 核心功能 |
|------|------|---------|
| 登录页 | `/login` | 手机号+验证码登录 |
| 聊天主页 | `/chat` | AI标识、消息列表、输入框、快捷工具 |
| 聊天详情 | `/chat/:id` | 单个对话的完整聊天记录 |
| 工具箱 | `/tools` | 工具列表、主动关怀卡片 |
| 大姨妈记录 | `/tools/period` | 日历视图、周期记录、预测 |
| 待办管理 | `/tools/todo` | 待办列表、提醒设置 |
| 倒数日 | `/tools/countdown` | 倒数日列表、新增 |
| 我的 | `/profile` | 用户信息、人格切换、设置入口 |
| 记忆管理 | `/profile/memories` | 记忆列表、编辑、删除 |
| 她的信 | `/tools/letters` | 每周一封信（本周真实数据本地生成） |
| 会员中心 | `/membership` | 权益对比、支付 |
| 设置 | `/settings` | 通知、隐私、关于、退出 |
| 危机干预 | (弹窗) | 热线号码、求助提示 |
| AI身份提示 | (弹窗) | 首次打开全屏提示 |
| 2小时提醒 | (弹窗) | 连续使用提醒 |

## 4. 用户流程

```
首次访问 → AI身份提示弹窗 → 登录/注册 → 聊天主页
    ↓
聊天主页 → 输入消息 → AI回复(人格风格) → 工具快捷入口
    ↓
工具箱 → 选择工具 → 工具详情页
    ↓
我的 → 人格切换 → 记忆管理 → 会员中心 → 设置
```

---

## 5. 技术约束

- 移动端优先响应式设计（原型393×852）
- 聊天消息实时渲染，打字动画
- 记忆系统基于PostgreSQL（简化版，预留向量搜索扩展）
- Mock对话引擎预留LLM API接口
- JWT鉴权，token过期自动刷新
- 所有页面需AI身份标识
- 危机干预关键词检测即时触发
