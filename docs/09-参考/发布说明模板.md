## 五、升级说明

### 从 v0.x.y-internal.(N-1) 升级

1. 备份：`pg_dump` 当前数据库
2. 拉取新镜像（不可变 tag：`______`）
3. 应用增量迁移：`prisma migrate deploy`（**不要**用 `db push`）
4. 重启 Compose：`docker compose up -d`
5. 验证：
   - `/api/health/live` 与 `/api/health/ready` 返回正常
   - 白名单用户登录通过
   - 发送一条消息，确认返回 `source` 字段
   - `/makeup/` 可打开并完成一次本地分析

### 回滚

1. 停止当前服务
2. 恢复 `pg_dump` 备份
3. 切回上一个镜像 tag：`______`
4. 验证上述同样 5 项

> 回滚演练必须在发布前完成，不能只写在文档里（Spec §9）。
