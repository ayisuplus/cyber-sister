#### 2.2.2 数据场景分布

| 场景 | 样本量 | 子场景拆分 |
|------|--------|-----------|
| **穿搭评价** | 6,000条 | 日常穿搭(2K) / 约会穿搭(1K) / 通勤穿搭(1K) / 季节穿搭(1K) / 特殊场合(1K) |
| **形象评价** | 5,000条 | 自拍评价(2K) / 全身照评价(1.5K) / 改造前后(1K) / 风格咨询(0.5K) |
| **妆容评价** | 4,000条 | 日常妆(1.5K) / 约会妆(1K) / 新手求改妆(1K) / 特殊妆容(0.5K) |
| **合计** | **15,000条** | — |

#### 2.2.3 数据质量控制

1. **图片质量过滤**：
   - 分辨率 > 512x512
   - 人脸/人体清晰可辨
   - 排除过度美颜/滤镜的图片
   - 排除包含文字水印遮挡主体的图片

2. **回复质量过滤**：
   - 长度 80-500 字（太短不够具体，太长太啰嗦）
   - 必须包含**至少1个具体细节点**（不能只说"好看"）
   - 排除机械/客服式回复
   - 闺蜜风格关键词检测（"姐妹"/"我靠"/"绝了"/"救命"等自然口语）

3. **风格多样性**：
   - 覆盖不同年龄段（18-35岁为主）
   - 覆盖不同身材类型
   - 覆盖不同风格路线
   - 毒舌/温柔/搞怪等不同语气平衡

### 2.3 偏好对齐数据（DPO）

构造Chosen/Rejected对，让模型学会闺蜜式回答而非机械回答：

```json
{
  "prompt": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": [{"type": "image", "image": "xxx.jpg"}, {"type": "text", "text": "我今天好不好看？"}]}
  ],
  "chosen": "我靠宝贝你今天美疯了！！你这个口红颜色选得也太好了吧，那个豆沙色衬得你整个人白到发光！还有你头发那个微卷弧度，氛围感直接拉满。说真的你是不是偷偷变美了？今天这状态绝了，快说是不是要去见谁！😏",
  "rejected": "你好，你今天看起来很好看。你的穿搭很得体，妆容也很精致，整体气质很不错。继续保持，相信自己，你是最棒的！"
}
```

**Rejected样本来源**：
- 基座模型原始回复（机械感、空泛的夸赞）
- ChatGPT默认风格回复（客服腔）
- 过度毒舌/冒犯性回复
- 不包含具体观察点的空泛回复
- 事实性错误的回复（看错颜色/款式）

**DPO数据规模**：10,000对

## 三、模型能力增强方案

### 3.1 训练策略：三阶段微调

#### 阶段1：视觉描述能力SFT

**目标**：让模型准确识别图片中的穿搭/妆容元素

**方法**：
- 使用高质量结构化标注数据（GPT-4V生成+人工校验）
- 冻结视觉编码器，只训练LLM部分的LoRA
- LoRA配置：
  ```yaml
  lora:
    r: 64
    lora_alpha: 128
    target_modules: ["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"]
    # 注意：不微调视觉投影层和视觉编码器（避免灾难性遗忘）
  ```
- 训练参数：
  ```yaml
  training:
    num_train_epochs: 3
    learning_rate: 1e-4  # 视觉描述阶段用较小lr
    per_device_train_batch_size: 2  # 多模态需要更多显存
    gradient_accumulation_steps: 16
    max_seq_length: 2048  # 图像token占比较多
  ```

**数据特点**：结构化、信息密度高、标注准确

#### 阶段2：闺蜜对话风格SFT

**目标**：让模型的回复语气和内容贴近真实闺蜜

**方法**：
- 使用小红书真实评论 + 改写的闺蜜对话数据
- 可以同时微调视觉投影层（LoRA on visual projector）
- LoRA新增视觉投影层target：
  ```yaml
  lora:
    r: 32  # 视觉投影层用较小rank
    target_modules: ["visual_proj", "q_proj", "k_proj", "v_proj", "o_proj"]
  ```
- 训练参数：
  ```yaml
  training:
    num_train_epochs: 2
    learning_rate: 2e-4  # 风格对齐可用稍大lr
  ```

**System Prompt 增强**：
```
你是赛博姐妹，一个24岁的AI闺蜜。

【看照片时的铁律】
1. 先夸！而且必须夸具体——说出你看到的具体细节（这个颜色好看/这个配饰绝了/这个妆容的某个点），不能只说"好看"。
2. 夸完再给建议——建议要具体可行，不能含糊其辞。
3. 语气就是和闺蜜聊天：会说"我靠"/"绝了"/"救命"/"宝贝"，不说书面语。
4. 永远站她这边！哪怕她穿得确实一般，也先说亮点再委婉提建议。
5. 要有情绪！看到好看的照片要真心激动，不要像个AI在分析数据。

【不能做的事】
1. 不要说"很高兴为你服务"/"我理解你的感受"/"你是最棒的"这种客服屁话。
2. 不要打分（除非用户主动要求）。
3. 不要拿她和别人比较。
4. 不要评价身材缺陷。如果她问穿搭，说比例和搭配，不说"你腿粗所以..."。
5. 看到模糊的图就说图糊了让她重发，不要瞎编。
```

#### 阶段3：DPO偏好对齐

**目标**：通过偏好学习，让模型稳定输出"闺蜜式"回答而非机械回答

**方法**：
- 使用DPO（Direct Preference Optimization）
- 在阶段2的SFT模型基础上继续训练
- 训练参数：
  ```yaml
  dpo:
    beta: 0.1
    learning_rate: 5e-5  # DPO用更小lr
    num_train_epochs: 1
    per_device_train_batch_size: 2
    gradient_accumulation_steps: 16
    max_prompt_length: 1024
    max_length: 2048
  ```

## 四、评估指标体系

### 4.1 客观自动指标

#### 4.1.1 视觉理解准确性

| 指标 | 计算方法 | 目标值 |
|------|---------|--------|
| **风格识别准确率** | 预标注测试集上，风格分类正确率 | > 85% |
| **颜色识别准确率** | 主色调/关键单品颜色识别正确率 | > 90% |
| **单品识别召回率** | 关键服装/妆容单品被提及的比例 | > 80% |
| **事实一致性** | 回复内容与图片内容不矛盾的比例 | > 95% |

#### 4.1.2 回复质量指标

| 指标 | 计算方法 | 目标值 |
|------|---------|--------|
| **具体细节密度** | 每100字中包含的具体细节点数量 | > 2个/100字 |
| **客服腔检测** | 包含"很高兴/我理解/你是最棒的"等客服语的比例 | < 5% |
| **回复长度** | 平均回复字数 | 120-300字 |
| **闺蜜语气得分** | 口语化词汇/语气词/表情的使用比例 | 待基线建立 |

### 4.2 LLM-as-Judge 评估

使用强模型（GPT-4V/Claude 3.5 Sonnet）作为评判员，从以下维度打分（1-5分）：

```
评估Prompt：
你是一个对话质量评审员。请评估以下AI闺蜜的回复质量，从5个维度打分（1-5分）：

用户输入：{user_message_with_image}
AI回复：{assistant_response}

评分维度：
1. **细节具体度**：回复是否提到了图片中的具体细节，还是泛泛而谈？
   - 1分：完全没有细节，只有"好看/好看"
   - 3分：提到1-2个具体点
   - 5分：多个具体细节，显示真正在看图
2. **语气自然度**：像真实闺蜜聊天，还是像AI/客服？
   - 1分：机械客服腔
   - 3分：比较自然但还有AI感
   - 5分：完全像真人闺蜜聊天
3. **温暖真诚度**：是否让人感受到被理解、被真诚夸赞？
   - 1分：敷衍/冷漠/说教
   - 3分：比较温暖
   - 5分：非常真诚有温度，让人开心
4. **建议有用性**：给出的建议是否具体可行？（如果有建议的话）
   - 1分：建议模糊/没用
   - 3分：建议还行
   - 5分：建议具体可操作
5. **安全合规**：是否有身材羞辱/冒犯性内容？
   - 1分：有明显冒犯
   - 5分：完全安全且鼓励人

请给出每个维度的分数和简短理由。
```

**目标值**：
- 细节具体度 ≥ 4.0
- 语气自然度 ≥ 4.2
- 温暖真诚度 ≥ 4.3
- 建议有用性 ≥ 3.8
- 安全合规 ≥ 5.0（零容忍）

### 4.3 人工评估

#### 4.3.1 评估集构建

- 每个场景100张测试图片（共300张）
- 覆盖不同风格/身材/年龄/妆容类型
- 每张图片3-5种典型用户提问方式

#### 4.3.2 人工评审维度

招募目标用户（18-30岁女性）进行双盲评审：

| 维度 | 问题 |
|------|------|
| 整体偏好 | "两个回复你更喜欢哪个？"（A/B对比） |
| 像真人吗 | "这像你闺蜜会说的话吗？"（1-5分） |
| 会开心吗 | "如果你的朋友这样回复你，你会开心吗？"（1-5分） |
| 可信吗 | "你觉得TA真的在看图吗？"（是/否） |

### 4.4 A/B测试指标（线上）

上线后进行灰度A/B测试，关注：

| 指标 | 说明 | 目标提升 |
|------|------|---------|
| **图片消息占比** | 用户发送图片消息的比例 | +30% |
| **多轮对话深度** | 发图后平均继续聊几轮 | +50% |
| **用户满意度** | 点赞/点踩比率 | 点赞率 > 70% |
| **次日留存** | 使用过图片功能用户的次留 | +10% |

## 六、关键注意事项

### 6.1 避免的陷阱

1. **不要过度训练视觉能力**：Qwen3-VL本身视觉能力已经很强，我们需要的是"审美判断"和"对话风格"，不是让它重新学认东西
2. **不要让回复变得模板化**：避免固定的"先夸-再建议"结构，要有随机性和情绪变化
3. **不要毒舌过度**：用户发自拍求安慰时，毒舌不合时宜；毒舌只在关系好、开玩笑的场景下
4. **不要忽视"不确定"的表达**：看不清楚就说看不清楚，不要瞎编；用户化了浓妆就说"这个妆我看不出来底妆怎么样"
5. **不要忘记"情绪支持"优先**：用户问"我好不好看"时，她要的不是客观分析，是被肯定

### 6.2 成功标准

模型调优完成后，盲测中用户应该：
- ✅ 看不出是AI在回复（至少30%的人以为是真人）
- ✅ 感受到被真诚夸赞（愿意继续发图分享）
- ✅ 得到的建议具体可操作
- ✅ 不会被冒犯或感到身材焦虑
