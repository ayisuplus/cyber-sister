## 一、服务说明

Amie（"本服务"）是一款由 AI 驱动的中文陪伴产品，面向**中国成年用户**提供对话陪伴与实用工具（待办、倒数日、经期记录、提醒）以及 AI 妆教功能。

### 1.1 服务的性质

**本服务由人工智能提供，所有回复均由模型自动生成，不代表运营方观点。**

- AI 回复**可能不准确、不完整或存在编造**，重要信息请自行核实
- 本服务**不提供**医疗诊断、心理咨询、法律或财务建议
- 本服务**不是**紧急救助渠道

### 1.2 内测阶段的特别说明

当前版本为**受限内测**：

- 仅面向受邀的成年测试者，通过白名单手机号登录
- 需通过 VPN 或可信网络访问
- **不代表正式公开发布、医疗服务或法律合规认证**
- 功能可能随时调整、暂停或终止，且不另行通知
- 可能存在缺陷，你的反馈对改进至关重要

### 1.3 明确不提供的能力

以下能力当前**未提供**，如页面出现相关入口，均属占位或"接入中"状态：

- 真实支付与会员充值
- 虚拟试衣/化妆间的图像生成
- 天气数据
- 语音、图片生成
- 真实短信验证码
- 账号自助删除

我们不隐瞒未完成的功能，也不会以"即将上线"诱导你付费或提供更多信息。

## 三、用户行为规范

你同意**不**使用本服务从事以下行为：

| 禁止行为 | 说明 |
|----------|------|
| **违法违规** | 违反中华人民共和国法律法规 |
| **生成有害内容** | 诱导、教唆、传播危害国家安全、淫秽色情、暴力恐怖等内容 |
| **伤害自己或他人** | 寻求、提供或美化自伤、伤害他人的方法 |
| **滥用安全机制** | 反复尝试绕过危机检测、安全过滤或身份标识 |
| **技术攻击** | 逆向、渗透、注入、爬取、压测、干扰服务正常运行 |
| **冒用身份** | 冒充他人或伪造身份信息 |
| **商业滥用** | 未经许可批量调用、转售、二次分发服务内容 |
| **训练数据爬取** | 批量导出对话内容用于训练竞争性模型 |

我们有权对违反上述规范的用户**停止服务**，且不承担因此产生的责任。

- 我们努力保持服务稳定，但**不保证无中断**

在法律允许的最大范围内，我们对因使用本服务产生的**间接损失、附带损失、利润损失、数据损失**不承担责任。

上述限制**不适用于**：因我们故意或重大过失造成的人身伤害，以及法律强制规定不可免除的责任。
