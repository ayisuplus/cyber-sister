## 引言

赛博姐妹（"我们"）是一款面向中国成年用户的 AI 陪伴产品。我们深知，你愿意把心里话说给一个 AI 听，本身就是一种信任。这份政策用尽量直白的话说明：我们收集什么、怎么用、怎么保护、以及你能怎么管。

**一句话版本**：聊天尽可能在你自己的机器上完成，送给 AI 的内容会脱敏，日志不记聊天内容，你的自拍照从不上传，你随时可以删掉我们记住的一切。

## 一、我们收集哪些信息

### 1.1 你主动提供的

| 信息 | 用途 | 是否必须 |
|------|------|----------|
| 手机号 | 登录验证、账号识别 | 是（登录必需） |
| 聊天内容 | 生成回复、展示历史 | 是（服务核心） |
| 记忆内容 | 让你不用重复说 | 否（你自主创建） |
| 工具箱数据（待办、倒数日、经期、提醒） | 提供工具功能 | 否 |
| 人格偏好 | 决定她的说话方式 | 否（有默认值） |

> 「帮我记住」的记忆建议候选由本机模型临时生成，仅在你的设备本地处理、不落库；只有你确认后才会成为上表中的记忆内容。

### 1.2 我们自动记录的

| 信息 | 用途 | 说明 |
|------|------|------|
| 登录与刷新令牌（服务端只存哈希） | 保持登录、安全轮换 | 令牌本身不落库 |
| 请求日志 | 排查故障、保障安全 | **只含** request ID、场景、模型名、重试次数、耗时、结果 |
| 功能使用事件 | 了解哪些功能被用 | 不含聊天内容 |

### 1.3 明确不收集的

- ❌ **你的自拍原图**：美颜相机与虚拟房间的照片**只在你这台设备上处理**（虚拟房间经本机 ComfyUI 生图，见 §3.5），不送往任何外部服务
- ❌ **通讯录、位置、相册、麦克风**：不申请、不采集
- ❌ **设备指纹、广告标识符**：不做用户追踪，不接第三方广告 SDK

## 二、我们如何使用信息

只用在这几件事上，**不用于广告、不出售给第三方**：

1. **提供服务**：生成回复、保存历史、管理工具数据
2. **保障安全**：危机识别、异常登录检测、防滥用
3. **排查故障**：通过请求日志定位问题
4. **改进产品**：基于聚合的、去标识化的使用统计

**我们不会**：

- 用你的聊天内容训练公开模型（内测期间）
- 把你的数据卖给任何第三方
- 向你推送基于画像的定向广告

## 三、信息如何流转

### 3.1 本地优先

默认路径是**本地模型（llama.cpp）**：你的消息送到你自己部署的模型，不经过我们的服务器转发至第三方。

### 3.2 云端模型（需要你同意）

经批准的外部模型在两种部署形态下使用，规则一致：

- **本地优先部署**：仅当本地模型不可用时，可选的云端备用可能被启用
- **外部主用部署**（`EXTERNAL_CHAT_PRIMARY`）：聊天与解释直接由云端模型提供，本地模型变为可选回退；此时消息列表以「云端模型」徽标标明

两条路径共用以下规则：

- **必须你主动同意**才可能启用，默认关闭
- **不同意完全不影响**本地优先部署的聊天功能（外部主用部署下则聊天不可用）
- **随时可撤回**，撤回后立即生效
- 同意状态以服务端为准，页面不会用弹窗阻断你使用本地聊天

### 3.3 送给模型前会做什么处理

无论走哪条路径，送入任何模型的内容都遵守：

- 业务消息最多 **20 条**（19 条历史 + 当前输入），按时间旧到新
- 只含角色和**脱敏后**的内容
- 记忆最多注入 **5 条**，且必须是与当前输入有明确重合的
- **手机号、邮箱、证件号等确定性脱敏**
- 不发送用户 ID、手机号字段、时间戳、图片、日志或无关记忆
- 日记回应（「让姐妹看看」）：仅该篇日记正文经脱敏后送入模型；手帐鼓励（「姐妹说两句」）：只送习惯名、连续天数与今日完成计数，不送任何正文。两者都沿用 §3.2 的同意门

### 3.4 日志

日志只记录：request ID、场景、模型/供应商、尝试次数、延迟、结果。

**不记录**：提示词正文、聊天内容、记忆内容、凭据、图片。

### 3.5 虚拟化妆间 / 虚拟试衣间的照片

使用这两个房间（`/tools/virtual-makeup`、`/tools/virtual-fitting`）生成预览时，你选择的照片会经浏览器 → 本机 API → 本机 ComfyUI 处理：**全程只在你的这台设备内存中流转，不落库、不保存副本、不送往任何外部模型或外部生图服务**。

## 四、我们如何保护信息

| 措施 | 说明 |
|------|------|
| **本地推理** | 默认路径不出你的部署环境 |
| **传输加密** | HTTPS/TLS 全程加密 |
| **令牌安全** | refresh token 仅存于 Secure + HttpOnly Cookie，服务端只保存哈希，每次使用轮换 |
| **脱敏** | 送模型前对个人标识信息做确定性脱敏 |
| **日志最小化** | 不落库聊天正文 |
| **访问控制** | 密钥、白名单、模型地址等配置不进代码仓库，通过外部只读文件挂载 |
| **数据库** | 只通过受控迁移变更，发布前备份 |

> 我们不会声称"绝对安全"——没有任何系统能做到。但上面这些是我们实际做了的，不是宣传话术。

你可以随时：

| 权利 | 怎么做 |
|------|--------|
| **查看** | 「我的」→「记忆」查看她记住的全部内容 |

| **删除单条** | 记忆列表中删除 |
| **删除全部** | 记忆页一键清空 |
| **导出** | ⚠️ 内测版暂不支持，已列入后置计划 |
| **删除账号** | ⚠️ 内测版暂不支持（后置项），当前可清空记忆 |

**需要帮助**：如需我们协助处理你的数据，通过下方联系方式提出。

## 六、未成年人保护

- 本服务**面向成年人**，内测为白名单邀请制，仅面向成年测试者
- 我们不面向未满 18 周岁的用户提供服务
- 如发现未成年人使用，我们将停止服务并删除相关数据
- 监护人如认为被监护人使用了本服务，请联系我们处理

> 未成年人保护的具体技术措施见 [`docs/01-产品/开发计划与路线图.md`](../01-产品/开发计划与路线图.md) W3-3。

## 七、关于 AI 的特别告知

请你始终记住：

- **她是 AI，不是真人**。每个界面都有身份标识
- 她的回复由模型生成，**可能不准确、可能编造信息**，重要事项请自行核实
- **她不做心理咨询或医疗诊断**，不能替代专业人士
- **她不会替你做重大决定**

当她说的内容涉及伤害自己或他人时，我们会中断 AI 回复并提供求助资源。这些资源经人工核验，但不保证可用性——**遇到紧急情况请直接联系当地紧急服务或专业机构**。
