## 使用方式

1. 发布前由**发布负责人**逐项检查并填写结果
2. 每项标记：✅ 通过 / ⚠️ 有条件通过（须说明条件与批准人）/ ❌ 未通过 / ➖ 不适用
3. **阻塞级**项目 ❌ 未通过 → 不得发布，无例外
4. 完成后由产品负责人与技术负责人共同签字
5. 本清单随 Release Notes 归档
