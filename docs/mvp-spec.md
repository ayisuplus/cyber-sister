# 妆语 MakeupWhisper — MVP 产品规格

> 帮中国女生找到适合自己的妆容，并手把手教会的闺蜜感工具。

## 1. 产品名称

**妆语**（MakeupWhisper）

取"妆容"+"私语"之意，定位像闺蜜贴耳教你化妆，不是冷冰冰的算法。

## 2. 目标用户

- **人群**：中国女性，18–35 岁
- **城市**：一线/新一线为主，下沉市场为增量
- **化妆水平**：初学者（约 60%）+ 中级想进阶（约 40%）
- **痛点**：
  - 看博主教程"照搬"到自己脸上完全不像
  - 不知道自己的脸型/眼型适合什么风格
  - 买了热门色号不适合自己
  - 步骤多、术语多，缺少一对一引导

## 3. 核心流程

```
[上传自拍] → [AI 分析五官] → [推荐 3 个妆容] → [分步教学] → [分享结果卡]
   (1)           (2)              (3)                (4)         (5)
```

### 3.1 上传自拍
- 入口：首页大按钮"上传自拍，开始分析"
- 要求：正脸、表情自然、光线均匀、无遮挡（刘海/墨镜）
- 实时引导：检测到偏头/遮挡时给文字提示
- 隐私承诺：图片仅在浏览器本地分析，不上传原图到服务器

### 3.2 AI 分析五官
- 维度：
  - **三庭**：上庭/中庭/下庭比例
  - **五眼**：五眼宽度、双眼距离
  - **脸型**：椭圆/圆/方/心形/长/菱形
  - **肤色**：冷白皮/暖白皮/自然色/小麦色/深肤色 + 冷暖倾向
  - **眼型**：杏眼/圆眼/肿泡眼/单眼皮/下垂眼/上挑眼/眼距宽/眼距近
  - **鼻型**：直鼻/宽鼻梁/窄鼻梁/鼻头圆/翘鼻/鹰钩鼻
  - **眉型**：眉弓角度、眉眼距
- 产出：用户可读的"五官报告卡"，每项配口语化解释
- 置信度：低置信度项明确标"仅供参考"

### 3.3 推荐 3 个妆容
- 排序逻辑：匹配度从高到低，每个妆容说明"为什么适合你"
- 每个妆容包含：场景标签（通勤/约会/出游/面试）、风格名、3-5 张参考示意
- 附带"避雷提示"：告诉你这个妆要避免什么雷区

### 3.4 分步教学
- 在用户原照片上**分区覆盖标注**（底妆/眉/眼/腮/唇等）
- 每步包含：动作名称、工具提示、刷色方向、推荐色系、避坑
- 用户可点击"上一步/下一步"或自由跳到任意步骤
- 完成度进度条

### 3.5 分享结果卡
- 静态图片：用户原图 + 五官分析摘要 + 选定妆容
- 二维码扫码可回看自己的教程
- 一键复制"闺蜜种草文"（自动生成带妆容关键词的分享文案）

## 4. 成功指标

| 指标 | 定义 | MVP 目标 |
|------|------|---------|
| **上传率** | 落地页 → 成功上传 | ≥ 40% |
| **分析信任度** | 看完报告卡后点"分析得挺准"比例 | ≥ 60% |
| **教程完成率** | 进入教学后完成 ≥ 80% 步骤 | ≥ 35% |
| **分享率** | 完成分析/教学后点击分享 | ≥ 15% |
| **D7 留存** | 7 天内回访 ≥ 2 次 | ≥ 10% |

## 5. 非目标（明确不做）

- ❌ 医疗/皮肤疾病诊断
- ❌ 明星脸/网红脸复刻
- ❌ AI 实时试妆（virtual try-on）
- ❌ 电商直接成交（只做种草，不做下单）
- ❌ 多人协作 / 社交关系链
- ❌ 跨境肤色 / 跨文化妆容分析（仅中国女生）

## 6. 视觉与文案规范

- **色系**：粉色系（#FFB6C1 主色，#FFC0CB 辅色，#FF69B4 强调）
- **形状**：圆角卡片，柔和阴影
- **字体**：无衬线正文 + 手写体点缀（标题、强调）
- **语气**：闺蜜口吻，称呼"你"，避免"亲""宝宝"
- **文案**：全中文，无英文术语混排（必要专业词配括注）

## 7. 风险与权衡

- **人脸数据合规**：MVP 阶段全部本地处理，不上传原图；后期如需云端分析，需明确用户授权与数据脱敏
- **AI 误判**：低置信度项必须显式提示，避免误导
- **审美单一**：3 个妆容要覆盖不同风格（不是同一个模板换色）
- **教程可执行性**：步骤描述要能在 30 秒内完成单步
