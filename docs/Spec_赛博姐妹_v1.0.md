# 赛博姐妹单机内测规格 v1.0

> 状态：四周内测实施基线
> 更新日期：2026-09-07（云端切割：云端唯一路径，本地模型面与服务器侧执行能力删除）
> 目标日期：2026-10-01
> 适用范围：中国区、中文优先、VPN/可信私网中的白名单成年测试者

## 1. 产品与架构边界

当前产品是模块化单体，不是微服务平台。单机 Docker Compose 运行 Nginx、主 Web、API、PostgreSQL 和一次性 migration job。Nginx 提供用户域名上的 TLS，同源暴露 `/api/`。

2026-09-07 云端切割（用户拍板）：目标用户是手机用户，跑不了本地模型，聊天从「llama.cpp 本地优先 + Qwen 备用」切换为**云端唯一路径**（供应商槽 `GATEWAY_QWEN_*`，供应商中立）；llama.cpp 管理面、虚拟试衣/化妆间（本机 ComfyUI）、服务器侧执行能力（bash_run、内置浏览器、工作模式生图、SKILL.md 技能、JS 插件、MCP）全部删除下线。

内测只正式暴露：

- 白名单登录、refresh 轮换和 logout 撤销。
- 云端模型的分句流式 AI 聊天与六种用户级人格（`toxic | gentle | rational | energetic | sister | cool`），同一同意门下按需记忆建议。
- `cloud-primary-v1` 云端模型同意、拒绝和撤回（旧版同意自动回到未选择状态，见 §3）。
- 用户主动维护的显式记忆。
- 服务端危机阻断和安全输出过滤。
- 姐妹工具箱：日程（按天时间线，可带日期与时间）、倒数日、经期记录与预测、提醒设置（喝水/睡觉/经期）、日记、手帐打卡、阅读、自习。
- 智能体工具回路（§4.1）与工作模式（日程四件、计算换算、联网搜索、写作/翻译/计划，无服务器侧执行能力）。
- 美颜相机：MediaPipe WASM 全程浏览器内处理，照片不上传。
- 本机 FunASR 语音转文字（sidecar，不送外部服务）。

天气、会员、支付、账号删除、真实短信、自动记忆、向量检索、模型训练、微服务/Kubernetes/Redis、公开发布均为后置项。

## 2. 认证合同

- 仅 `APP_ENV=internal` 允许 `INTERNAL_TEST_PHONES` 和 `INTERNAL_TEST_CODE`；其他环境配置固定验证码必须拒绝启动。
- 非白名单号码和错误验证码统一返回通用 401，不泄漏白名单状态。
- 登录限流按 IP 与手机号组合执行，内测单实例不引入 Redis。
- access token 用于 API 鉴权；refresh token 只存于 `Secure`、`HttpOnly` cookie，服务端只保存 token hash。
- refresh 每次轮换；旧 token 重放失败。logout 撤销当前 refresh token、清 cookie，重复调用幂等。
- 客户端没有“获取验证码”交互，登录必须等待真实 API 结果。

## 3. 用户、人格与同意

`User.persona` 是唯一人格来源，允许 `toxic | gentle | rational | energetic | sister | cool`。`PUT /api/user/persona` 后，当前及未来会话的下一条消息立即使用新人格；会话历史和记忆不改变。`Conversation` 不保存 persona。

云端切割后，云端模型同意是**一切模型调用的前置条件**（聊天、记忆候选、日记/手帐/阅读/自习短评）：未选择、拒绝或撤回时云端调用次数为零，相应能力不可用。用户拥有三态外部模型同意：

- `GET /api/user/external-llm-consent` 返回 `{accepted:null|boolean, version:"cloud-primary-v1", updatedAt}`。
- `PUT /api/user/external-llm-consent {accepted:boolean}` 记录接受或拒绝；把已接受状态改为 `false` 即撤回。
- 同意版本不是 `cloud-primary-v1` 时按未选择处理，不能触发外部调用；2026-09-07 云端切割时版本由 `qwen-fallback-v1` 升级，旧版同意全部自动回到未选择，因数据处理的范围与目的已实质变化，须重新取得同意。

同意门由服务端执行：每个云端调用发出请求前都必须重新读取数据库中的当前同意状态，因此用户在某次调用等待期间撤回授权也会阻止尚未发出的请求。新用户进入聊天即经首屏同意门（`CloudFallbackNotice`）授权或拒绝；拒绝后可随时在「我的 → 云端模型」改变主意。

## 3.1 云端唯一路径（2026-09-07 起，取代原外部主用部署模式）

聊天与解释场景只有云端一条路径，供应商槽为 `GATEWAY_QWEN_*`（任意 OpenAI 兼容端点，供应商中立，不在代码中硬编码任何具体供应商）：

- `/api/llm/status` 的 `mode` 恒为 `external_primary`，`local` 段固定 `{ configured:false, state:'removed' }`。
- 供应商未配置时聊天与解释返回 503 `LLM_UNAVAILABLE`；配置但未获同意时返回 503 `CLOUD_NOT_CONSENTED`（详见 §4）。
- 记忆建议（§4.1 的按需候选）与日记/手帐/阅读/自习短评走同一云端路径与同一同意门。
- 供应商地址、模型与凭据只来自部署环境（密钥只读文件），不从页面接收。
- 危机干预与本地安全模板是纯本地实现，云端供应商不可用时仍然工作。


## 4. 聊天与外发合同

聊天发送请求保持 `{content}`，默认为分句流式（SSE，完整句安全检查后下发；旧 JSON 端点保持兼容）：

- 成功：`{status:"ok", userMessage, aiMessage, source:"qwen"|"local_template"}`。
- 危机阻断：`{status:"blocked", userMessage, intervention:{level,message,resources}}`。
- 云端供应商未配置：503 `LLM_UNAVAILABLE`。
- 已配置但用户未同意（或同意版本不匹配/已撤回）：503 `CLOUD_NOT_CONSENTED`。
- 已同意且供应商已配置但所有候选都不可用：503 `LLM_UNAVAILABLE`。

成功响应的 `source` 为 `qwen | local_template`。任何模型失败时该次消息都不持久化，前端保留输入供重试。

云端供应商使用 OpenAI-compatible 接口（非流式 `stream:false` 或流式 SSE 分片），地址、模型与凭据只来自部署环境。送入任何模型的负载遵守：

- 系统提示另计；业务消息最多 20 条，按旧到新排列，即最多 19 条历史加当前输入。
- 业务消息只含 `role` 和脱敏后的 `content`。
- 最多注入 5 条与当前输入存在确定性词/标签重合的显式记忆；importance 仅在相关结果内排序。
- 手机号、邮箱、证件号等确定性脱敏；不发送用户 ID、用户手机号字段、时间戳、图片、日志或无关记忆。
- 输出命中威胁、拱火、浪漫化伤害、冒充真人或替用户决定重大人生事项等红线时替换为安全模板。

六套版本化人格提示允许网络化表达和轻度脏话，但 AI 身份、安全边界和用户自主性不可被人格或用户提示覆盖。

## 4.1 智能体工具回路（2026-09-07 修订）

聊天回路允许模型以整段 JSON（`{"tool":"注册名","args":{...}}`）请求调用产品内工具：服务端经既有领域服务校验执行（仅当前用户数据），结果以 system 消息回喂，最多 3 轮后强制文本回复。聊天模式工具域为日程/倒数日/经期/提醒/日记/手帐/阅读/自习/联网搜索；工作模式工具域为日程四件、计算与单位换算、联网搜索（联网搜索经普通 HTTP 请求，不驱动浏览器进程）。**不执行任意代码、不驱动浏览器、不在服务器执行 shell、不做服务器侧生图**，不向工具开放记忆写入、不开放外部 provider 直连。工具调用不产生任何面向用户的流式增量；每轮工具执行摘要以 `toolRuns` 随 AI 消息持久化，向用户明示。

## 5. 危机安全

危机检测发生在同意检查和模型调用之前。中高风险输入在一个数据库事务中写入用户消息、固定干预回复和唯一一条 `CrisisLog`，返回 `status:"blocked"`，模型调用次数必须为零。

仓库默认不提供未核验热线号码。展示资源必须由产品负责人书面批准，记录官方来源与核验日期；不得在没有证据时声明“24 小时”等可用性。

## 6. 显式记忆

新用户记忆为空。`/api/memories` 提供带当前用户归属检查的创建、列表、编辑、删除和清空接口，沿用 `semantic | episodic | procedural`、importance 与 tags。系统不自动提取、不由模型推断记忆。

## 7. 图像能力合同

- 虚拟化妆间/虚拟试衣间（本机 ComfyUI 生图）已于 2026-09-07 云端切割时移除下线：云端部署下「本机」语义不再成立，服务器侧生图与多租户共享主机不可兼得。
- 妆教模块（`/makeup/`）已于 2026-09-05 移除下线。
- 美颜相机保留并是当前唯一照片类能力：拍照或选照片后经 MediaPipe WASM 在浏览器内实时处理（磨皮/美白/瘦脸/大眼），照片不出这台设备、不发送任何服务。
- FunASR 语音转文字走本机 sidecar：音频经浏览器 → 主 API multipart 转发 → 本机 FunASR，不送任何外部服务；未配置或离线时如实 503。

## 8. 运行与数据

- 环境变量必须在业务模块加载前读取并严格校验；密钥、白名单、模型地址、域名和证书不得进入仓库。
- PostgreSQL 使用纯初始迁移；空库只能通过 `prisma migrate deploy` 建库，不允许 `db push`。
- migration job 成功后才启动 API；API ready 只检查 PostgreSQL，云端供应商未配置不视为应用宕机（聊天与解释仅返回 `LLM_UNAVAILABLE`）。
- `/api/health/live` 只表示进程存活；`/api/health/ready` 可随依赖恢复自动恢复。
- 登录用户通过 `/api/llm/status` 查看云端供应商是否已配置与当前同意状态。
- 日志只允许 request ID、scene、provider/model、尝试次数、延迟和结果，不记录提示词、正文、记忆、凭据或图片。
- 发布使用不可变镜像 tag。初始基线后只增量迁移；迁移前 `pg_dump`，并演练旧镜像和数据库恢复。

## 9. 发布验收

发布门要求：清洁检出后 frozen install、lint、typecheck、全部测试和构建通过；真实 PostgreSQL 迁移/重启/查询通过；真实云端供应商完成配置、同意、聊天、未同意阻断、供应商失败与重试验收；核心 Playwright E2E、安全、键盘、焦点、标签、live region、44px 触控、缩放、reduced-motion 与 axe 检查通过；危机和人格冻结输入集通过；Compose TLS、深链、健康依赖、持久卷、备份恢复和镜像回滚完成演练。

真实 Qwen 只做人工风格验收，必须在用户提供密钥并再次批准外部调用后执行。最终发布前的只读代码审查不得留有未解决的 P0/P1。该内测不等同于正式 WCAG、医疗或法律合规认证。
