标题:被职场霸凌？这5步送他进去！律师亲测有效
内容:
宝子们！被领导 PUA、同事孤立、恶意打低分真的不是玻璃心！🙅‍♀️
别忍气吞声！这 5 步教你合法维权，让霸凌者承担后果！
1️⃣ 紧急留痕！别硬刚别离职❗
证据是维权核心，立刻固定所有线索
✅ 必存证据：工作群 / 私信霸凌记录、语音转文字、同事证言、考勤异常、恶意绩效截图
✅ 高效存证：原画质截图 + 云端备份，用公证处电子数据存证工具（带法律时间戳，效力拉满）
❌ 避坑：别冲动离职（丧失索赔权）、别删记录、别口头争执（易被反咬）
2️⃣ 内部投诉！24 小时发书面函📩
书面形式锁定公司责任，直接抄作业
✅ 基础操作：OA 提交投诉 + 发公司邮箱（抄送 HRD、上级、法务）
✅ 核心话术：“本人遭 XX 职场霸凌（辱骂 / 恶意派活 / 孤立等），依据《民法典》991 条、《劳动合同法》38 条，要求公司 3 日内启动调查并书面反馈结果。”
✅ 加急操作：公司拖延就 EMS 寄纸质投诉函（备注 “职场霸凌投诉函”），保留签收记录
3️⃣ 同步取证！锁死公司 “不作为”🔒
公司敷衍时，固定其失职证据为后续索赔铺路
✅ 关键动作：记录沟通时间 / 内容（录音 + 纪要），拒绝无实质调解并书面回复
✅ 核心话术：“霸凌已涉名誉权侵权，拒绝无结果调解，要求公司依法处理，否则将启动仲裁与诉讼。”
❗ 要点：索要公司书面《调查结论》，哪怕 “无证据证明” 也是关键证据
4️⃣ 行政投诉 / 仲裁！官方渠道施压⚖️
公司不作为就找官方，精准倒逼整改
✅ 劳动监察投诉（恶意调岗 / 克扣工资）：说明公司拒不处理霸凌且存在违法用工，申请依法查处
✅ 劳动仲裁：依据《劳动合同法》38/46 条，主张被迫离职 + N 倍经济赔偿金
✅ 辅助渠道：性别歧视 / 长期侮辱类，向妇联 / 工会求助并留存记录
5️⃣ 刑民起诉！追究个人最终责任👊
霸凌升级为侮辱 / 诽谤 / 威胁，直接追责
✅ 民事起诉：依《民法典》1024 条，诉请停止侵害、赔礼道歉、赔偿精神损害抚慰金
✅ 刑事自诉：言论点击量超 5000 + 造成严重精神损害（附医院诊断），依《刑法》246 条指控侮辱 / 诽谤罪，最高判 3 年
❗ 要点：刑事自诉需备齐证据公证书、诊断证明、同事证言
